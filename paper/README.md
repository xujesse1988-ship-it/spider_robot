## 09-01 事实核查修正清单(改回去就是错的,动这些句子前先看源)

三路核查(代码/日志、n=3+标定报告、拟合+D′ 报告)对全文事实句逐条比对后改掉的口径:
- 传感器:机器人**有**六路吸盘压力传感器+母线电压/电流遥测(无 IMU、足底开关未接、舵机无回读)。
  只能写"交接不用任何传感反馈/不新增传感/无力传感",不能写"零传感器/no pressure feedback"。
- 气路:无储气罐、单泵直抽歧管;阀断电=吸盘↔歧管(失电安全),通电=通大气;单向阀在歧管—阀之间。
- 协议:n=3 九组**没有**内建 60s 静置(人工 21~58s;60s 内建 08-26 才加,只对 D′ 六组有效);
  腿间节拍=≥10s 且泵停 ≥2s,实际全由 10s 下限决定;首场电压 7.88V(非 ≥7.9);
  机位在 #1 A→B(~128px)、#2 C→A(数十 px)组间动过,"场内未动"是错的;组内漂移 ≤4.8px。
- 现象:软腿 vent 弹跳 L2 3.5/R2 6.1(5.8/5.9 是全周期列,HANDOVER-DESIGN §1 混列);脚回弹 9~15 为下限;
  静置段 2.4~4.7mm/组(不是"零");"131 vs 131.3"是分段和核对,其比例本就由该读数标定,不是独立验证。
- 模型:e/b=(K−k)/k 逐腿 1.7~8(非 5~8);"弹跳 21mm 饱和低于线性预测"是 08-20 推测且被 24~28 实测推翻,
  改为"硬腿 20~27 平台+模型高估前进损失 ⇒ 归因扭矩饱和(假说)";P2 首抬 n=3 基线 2.5~4.3 非 ≈0;
  P3 4.6 用的是斜率 k̂、RMSE 0.85 是 54 单元含共模项;P4 "全给一条 0%/非单调"不可复现已删,+30% 是温和档反向;
  B→C 跨指标 −30~−36%(非 −31~−33)。
- 方法:首轮指令伪迹按部署表仿真 ≈14mm(B)/20mm(C)(旧 ≤5mm 来自旧表);δ 表**未**在权重下重标,B/C 同一张表;
  "首版表 74→50"无此实验已删;代码 ≈150 行(含注释 270)。
- 结果:R1 上弹实测两次 ≈−0.9mm(B 组),−1~−3 是协议预期值;交接段占比 B 56~58%/C 47~62%;
  R1 交接段不逐轮增长;其余四腿 0~2mm;传递比"2 天 3 场 5 机位";相对效应重复间差 ≤5 点(非 3)。
