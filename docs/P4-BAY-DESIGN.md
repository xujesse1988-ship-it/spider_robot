# P4 电气+气动舱固定件 · 设计方案

目标:把 P4 吸附系统的全部电气/气动器件收进**一个可整体拆下的"舱"**,
固定在 MakeYourPet 机身(frame)顶面,几颗 M3 下机。现有实测尺寸已生成
**V0 试装版 STL**；生成器为独立的 `tools/generate_p4_bay_v0.py`,输出到
`hardware/climbing-parts/p4-bay-v0/`。V0 必须先通过 1mm 外廓模板和器件试装,
不能未经实装复核直接用于爬墙。

依据材料:
- 实物照片 `dianqi.jpg`(器件安装特征盘点的第一手来源)
- 连接拓扑 `html/p4-system-diagram.html`(电气三路 + 真空母线,决定相对位置)
- `docs/P3-GUIDE.md` 第 2 步"P4 气动舱固定件"行(已定约束:泵 TPU 软固定、
  阀阵列梁、罐抱箍、7 路传感器位+感测三通、PCB 柱、理线梳、整舱可拆、
  大质量件贴机身平面摊平、每腿服务环)
- 官方 `component-layout.jpg` + STL 实测:frame 198×205×16mm,
  top-cover4 占位 100×140mm,腹面另有 battery-bar(电池)与
  servo2040-bottom-cover(Servo2040 托盘)

---

## 0. 三个先定下来的架构决定

1. **电池和 Servo2040 不进舱,留在官方腹面位。**
   官方件 battery-bar(电池绑腹面)+ servo2040-bottom-cover(Servo2040 托盘)
   在 P3 打印清单里本来就要打。爬墙时腹面朝墙——电池是最重单件(~350g),
   放腹面恰好是全机离墙最近的位置,重心最优;18 根舵机线也天然在腹面汇聚。
   把它们搬上舱只有坏处。舱只需要:给 Pi↔Servo2040 的一根 USB 留下潜通道,
   给电池 XT60 线束留上行通道。
2. **"Servo2040 靠 Pi"立体实现。** Pi 放在舱前部、frame 中央开口正上方,
   Servo2040 在开口正下方的腹面托盘——两者垂直相邻,一根 15~20cm USB-C
   线穿开口直达。既满足"一根 USB 连线短",又不动 18 根舵机线。
3. **舱做上下两层:气动件贴底、电路板上甲板双面安装。** 原规划的
   110×95mm 夹层面积仅 10450mm²,而 Pi+分压板+5V 板自身面积已达
   12234mm²,物理上放不下。V0 改为 184×108×3mm 六柱电气甲板:
   Pi/分压板/5V 在顶面,MOSFET/继电器/2×XL6009 在底面;泵、阀、歧管和
   传感器仍贴底板。柱长改为 90mm,为泵、未来 Ø≤70 储气罐和甲板底面
   器件留出净空。

V0 底板外形 **190×130mm**(中央区域复用 top-cover4 的 100×140 接口边界,
左右外扩翼压在 frame 顶面实心区上,避开 6 个 coxa 舵机区——净空待实测 §4-14)。
V0 下层名义中心坐标为:阀轨 `(0,-48)`,泵适配板 `(-52,22)`,传感器座
`(45,22)`,两只歧管卡座 `(-55,-18)/(55,-18)`；歧管轴心为
`(0,-18,z=37)`。原点=底板中心,+Y 朝头,完整孔位见
`hardware/climbing-parts/p4-bay-v0/layout-report.json`。

### 2.2 逐条核对布局原则

| 原则 | 落实 |
|---|---|
| 大质量件贴机身平面摊平 | 电池(最重)在腹面=离墙最近;V0 单泵、阀、歧管贴底板;甲板只放 PCB。储气罐到货后仍优先贴底,但必须先按实测尺寸做 V1 抱箍 |
| XL6009 出 12V 紧邻 MOSFET 功率端 | 前半区并排,端子对端子,电源线 <50mm |
| MOSFET 输出端朝阀阵列 | 板输出侧朝后,正对中部阀轨,6 根阀线 <80mm;2 根泵线沿右缘理线梳到尾部 |
| 分压板紧邻 7 路传感器接入 | 分压板在夹层后缘,**正下方就是传感器排座**,7 路线垂直上行 <60mm;到 Pi 走 2×20 IDC 排线(P3 已定,禁杜邦) |
| Servo2040 靠 Pi(一根 USB) | 垂直相邻(§0-2),USB-C 线穿 frame 中央开口 |
| 5V 降压 USB-C 出口对 Pi 口 | 降压模块在 Pi 电源口同侧,出口对准,用 15cm 短线 |
| 气路一条龙 | 尾→前一直线:泵×2 →单向阀×2 →罐→罐口三通(罐压传感器=排座第 7 槽)→歧管→6 阀;全链在后半+中部连续,无跨区长管 |
| 6 阀出口朝六腿分散 | 阀轨横贯中部、正对 ML/MR 腿根;3 路出管向左、3 路向右,沿底板边缘扎带槽走到各腿根,**每腿过 coxa 留服务环**(松弛圈),舱缘扎带槽是最后锚点 |
| 泵震动隔离 | 自带 L 支架 + 3mm TPU 片 + TPU 垫圈,半浮动锁法(§3-3) |
| 电池可拆 | 腹面魔术贴/扎带,充电即取,不动舱 |
| 模块化 | 整舱一块底板,4~6 颗 M3 下机;电气甲板 6 颗 M3 柱,单独可拆;泵/阀/传感器/歧管固定件均通过孔阵列单换 |

### 2.3 高度与接口

- V0 底板 3mm,周边/开口加强筋再高 5mm,总高 8mm；电气甲板 3mm。
- 六根甲板柱长 90mm,甲板底面距底板平面约 93mm。按泵安装面+3mm TPU+
  支架轴高 28mm+电机半径 19mm 估算,泵顶约 58~60mm；余下约 33mm,
  扣除 6mm PCB 隔柱、约 2mm 板厚和保守 15mm 元件高度后还有约 10mm
  静态余量。打印柱仅供试装；正式爬墙优先换 M3×90 金属/尼龙六角柱或
  两段组合柱。泵和甲板底面 PCB 之间仍要实装
  检查端子、线弯和振动摆幅,不可只看静态包络。
- 与 frame 接口复用 top-cover4 四孔 `(±44,±40)`；V0 另预留 `(±44,0)`
  两个加强孔。后两孔须在 1mm 模板确认后才给 frame 钻 Ø2.8mm M3 自攻底孔,
  不确认不得钻。
- 底板中央开口为 70×108mm、R14,小于 frame 最小通孔 76×116mm、约 R18；
  用于 USB/传感器线/舵机线下潜。190×130mm 外廓到 coxa 线束的动态净空
  仍须用 `p4-bay-fit-template-v0.stl` 在装好腿和线夹的 frame 上复核。
- 泵排气口朝尾外,阀的侧向 Ø6 接口从阀轨开放侧伸出；12V 功率线和模拟
  传感器线使用不同理线梳。
- 走线纪律(P3 遗留):12V 功率线与 0.25~2.25V 模拟传感器线**分梳走线**,
  不同理线梳、不并捆;全舱禁面包板/杜邦,JST-XH 或焊线。

### 2.4 重量预算——先泼冷水

2.5kg 总预算 − P3 无吸附参考线 1.9kg = **吸附系统隐含预算仅 0.6kg**。粗估:

| 项 | 估重 g |
|---|---|
| 泵 ×2 | ~260 |
| 罐 | 60~100 |
| 阀 ×6 | 120~200 |
| 歧管+管路+接头+单向阀 | ~120 |
| 传感器 ×7 | ~40 |
| MOSFET + XL6009×2 + 分压板 | ~140 |
| 舱打印件 + 螺柱螺丝 | 200~250 |
| **合计** | **~940~1110** |

**超支 ~350~500g。**对策(按优先级):① 首飞只装单泵,双泵位留着、备泵
在架子上(−130g);② 罐选小号 250mL;③ 打印件以减重为一级目标——3mm 板
+镂空+筋,目标 ≤180g;④ 每件到货即称重记 `weight-log.md`,超 2.2kg
(无吸附)或预估整机超 2.7kg 时启动减重专项。**2.5kg 大概率守不住,
真实落点估计 2.6~2.8kg——这直接吃吸附裕量,P4 验收前要重算吸盘数值账。**

V0 按清单数量(不含 1mm 模板)的几何实体体积约 **237.2cm³**；若全部按
实心 PETG/TPU 计算,质量上限约 **301g**。切片器填充会降低实重,采购柱/隔柱
也会改变结果,但 3mm 大平板大部分仍接近实心。故 V0 的任务是确认孔位、
装配和线束,不是宣称达到 ≤180g；试装通过后再做 V1 镂空/薄壁减重并实称。

## 5. V0 生成器与交付

### 5.1 本版修正

| 原问题 | V0 处理 |
|---|---|
| 110×95 夹层放不下三块顶面 PCB | 改为 184×108 双面电气甲板,六柱支撑 |
| MOSFET 四孔不是对称矩形 | 按左下角四个实测坐标逐孔生成,不再用 `hx/hy` 猜孔距 |
| 泵支架实测 Ø5、48×28 四孔,旧方案写成 2×M3 | 改为独立适配板 4×Ø5.4,使用 4×M4+大垫圈+3mm TPU 垫 |
| 190×130 外扩后无法从裸 STL 得到 coxa 线束动态净空 | 单独生成 1mm 试装模板,模板通过前不打印正式底板、不钻新增孔 |
| 储气罐和 XT60 板式接口尺寸仍未知 | V0 不生成罐抱箍；XT60 改为扎带槽,避免假精确卡槽 |
| 一体底板改一个孔就要整件重打 | 底板改 M3 模块孔阵列,泵/阀/传感器/歧管均为独立可换件 |

### 5.4 首件实施顺序

1. 打 `p4-bay-fit-template-v0.stl`,装到已经装好 coxa 舵机和线夹的 frame；
   六条腿全行程慢速摆动,确认模板与线束/舵机无干涉。
2. 只用原 `(±44,±40)` 四孔固定模板。需要增强且确认落点为实心后,才在
   `(±44,0)` 钻 Ø2.8mm 底孔；此步骤不可从 STL 静态尺寸替代。
3. 分别打印泵适配板、阀轨、传感器座和歧管卡,拿实物逐件试插。卡位目标
   是可手装、无明显摇晃；不要靠螺丝强压尺寸不合的器件。
4. 打电气甲板,先不通电装全部 PCB,检查底面元件、端子和线弯是否互碰；
   Pi 用 M2.5,其余板用 M3,全部加 6mm 隔柱。
5. 前四步通过后再打正式底板并整舱装配称重。记录到 `docs/weight-log.md`,
   V0 先装单泵；是否加第二泵由真空建立时间和整机重量共同决定。

## 6. V1：按装配与连线审核修正版

V0 的 13 个 STL 单件网格虽然有效，但整舱审核发现开口凸筋与泵/阀/传感器
占位冲突、模块孔位不能形成完整紧固、下向针脚/阀嘴被遮挡，以及电气甲板
端子侧没有足够的插拔和弯线空间。V1 因此另建目录和生成器，**不覆盖 V0**。

### 6.1 结构与布线修正

| 审核问题 | V1 修正 |
|---|---|
| V0 只有一个泵位 | 左右两个 64 × 54 mm 共用适配板，中心 `(±46,24)`；右件旋转 180° |
| 开口凸筋侵占器件 | 正式底板改为 4 mm 平板；只保留三条与底板齐平的传感器桥承载梁 |
| 7 个传感器针脚下方不通 | 采用抬高桥，2+2+2+1 排布，桥板底面装配高度 16 mm，每只传感器有独立窗口 |
| 阀底嘴和侧嘴受阻 | 六阀竖装，底嘴向下、侧嘴朝 `-Y`；支撑只接触本体两侧 |
| 歧管卡与传感器桥相撞 | 卡座移到阀轨后侧，歧管轴线约 `(0,-49.5,65)` |
| V0 电气甲板闭口槽无法穿成品接头 | 改为三个开放至板边的缺口，并为所有螺钉端子保留 10–20 mm 服务区 |
| 功率/模拟线容易交叉 | 左侧两只 comb 专走 GPIO/传感器，右侧两只专走电池/泵/阀功率线 |
| V0 的 90 mm 夹层余量不足 | 支柱增至 100 mm；甲板装配高度为 `Z=104…107 mm` |
| 旧方案加入未确认的中间 frame 孔 | V1 只使用已确认的 `(±44,±40)` 四个车架孔 |

电气甲板顶面为分压汇接板、Pi 5、5 V 降压板；底面为继电器、
YYNMOS-8 和两块 XL6009。具体坐标、旋转、端口朝向、10 个线弯服务区以及
各孔绝对坐标见 `hardware/climbing-parts/p4-bay-v1/layout-report.json`。

### 6.2 生成与独立验证

间距和 10 个端子服务区通过；7 个传感器针脚、6 个阀底嘴的下向路径通过。
完整打印清单、装配方向和接线分区见
`hardware/climbing-parts/p4-bay-v1/README.md`。

### 6.3 校验边界

V1 仍不能绕过实物首件：必须先打印 fit template 做六腿全行程动态扫掠，
再复核 555 泵体相对支架孔中心的前后偏置、0520B 塑料嘴实际伸出量和打印
孔径公差。储气罐抱箍继续等实物耳距后再设计。
