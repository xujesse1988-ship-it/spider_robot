已定的规则（09-13，用户定，别再翻）：

- **地面脚吸盘轴尽量垂直地面**；斜了就抬起重放到最正点，**需要转 coxa 就转**；小步多迈勤重放。
- **脚压在地上滑不动** ⇒ "贴地随动"作废；所有挪脚都是抬起 → 摆 → 落下。
- 后腿在第 3 步就指正后固定（`3 b i`、`6 b i`），不等提示。
- 中腿最正也超 25° ⇒ 收起（`h`），从此四脚。
- **眼睛和屏幕不一致以眼睛为准**：屏幕说正眼睛看斜 → `>` 加该腿修正再 `v`；屏幕说斜眼睛看正（墙面脚波纹贴平后杆斜十几度看不出）→ 不理，墙面门槛 25°。
- **阀线圈（09-14）**：站着一律断电（不发热；被单向阀憋出的被动真空无妨）；抬腿前通电放气 0.3 s；某脚要抽气时其余所有没在状态机手里的盘先通电隔离（一路一路 0.1 s），吸住后断回；收在空中的腿无罐时断电、有罐时通电（空盘接歧管会把罐漏光）。引擎 `valve_open()` 统一管，`--dry` 的真阀镜像它。
- **墙面脚吸到 −60 即可，不监护泄气、不补抽**（`--attach-kpa`；状态机 `hold_watch=False`、泵 `pump_on_demand`）；互锁只看 ATTACHED 不看盘压门槛；盘压靠人看状态行 `盘差`。
- **墙面脚吸盘轴离墙法线容差 25°**（`--wall-tilt`，落点带与保持同一个数；地面吸附脚仍 12/15，只承重脚 35）。提示在"再抬一档到 22° 以上"就叫重放，留 3° 给交接——两只前脚都贴着 25° 时重放谁都被对面的份额顶过线（09-14 干跑），提示会写"先 ↓ 一档再 v"。

## 2. 不变的几何规律（结论，推导见 HISTORY §1）

- 吸盘轴永远在腿平面内，coxa 只转这个平面。面外倾角：地面足 asin(sinφ·|sinβ|)、墙面足 asin(cosφ·|sinβ|)（φ 俯仰，β 腿平面相对机身 x 轴）。
  ⇒ 前腿指正前、后腿指正后任何俯仰都能对正两个面；中腿 coxa 摆到极限也只到 β≈35°，对地面吸附只到 φ≤26°，对墙面要 φ≥70~75°。**过渡顺序只能前 → 后 → 中。**
- 只压不吸的脚不受吸盘密封 15° 管，容差 35°（台架实测 35° 仍压得住）；中腿只压不吸时**腿长不是限制，髋高才是**（上限约 195 mm），倾角封顶 35°。
- 吸盘轴 ⊥ 面的站位半径 176.6 只由髋足距离决定；挪落点要**绕髋摆**，平移会拉长半径把盘拧斜。中腿斜的大头是面外分量 ≈ 俯仰角，收腿收不掉，只有转 coxa。
- 后腿要等髋离地约 250 mm（指令 72.5°）才落得到墙上。

## 4. 头号问题：机身沉降让模型和实机脱节 —— 系统解法（09-13 提案，待拍板）

### 4.1 问题到底是什么

引擎的世界系相对真机有 **4 个自由度没被钉住**，现在只有一个能输入：

| 自由度 | 现状 | 误差量级 |
|---|---|---|
| x（离墙） | 就位暂停按 `d` 输一次，之后不再修 | 平身时准（±3）；抬头后前脚近墙 10~20 mm |
| 偏航 | 从没量过、没处输入 | 两前脚离墙差 14 mm ≈ 6° |
| z（机身高） | 没有；靠 `wall_trim`、`+`×N、`floor-clear`、`FEMUR_SAG` 各补各的 | 站着 −21.5，16° 时 −40，随载荷状态变 |
| 俯仰 | 没有；靠"真实 = 0.891×指令 − 3°"在纸上折算 | 16° 差 4.7° |

误差来源是**受载让位**：DS3235 舵机带载会往回让几度（齿隙 + PID 静差），三个关节 × 百毫米杆件到足端就是十几二十毫米，加上吸盘波纹压缩 11~13 mm 和打印件变形。它随每条腿的受力变，而受力随姿态、几条腿在地、谁刚抬过而变——**所以它永远不会是一个常数，任何"再加一个常数"的补法都会在下一个工况失效。**

用 09-13 晚的实机数据核过一遍（`~/tmp/wall-sag/rigid_check.py`，只用引擎自己的坐标变换）：

| | 模型 | 刚体修正（低 40、俯仰 −4.7°） | 实机 |
|---|---|---|---|
| 16° 时 L1 悬停点比命令低 | 0 | **58** | **60** |
| 16° 时 L1 悬停点比模型近墙 | 0 | 11 | ≥ 20 |
| 0° 时 R1 / L1 近墙 | 0 / 0 | ≤ 5 / ≤ 5 | 20 / 6 |

⇒ **高度误差几乎全是刚体位姿误差**（一个机身低多少 + 俯仰实现率），刚体修正就能吃掉；**离墙误差里有一半是刚体、另一半是左右不对称**（偏航或右前腿本身），刚体修正治不了，要单独量或单独修。这两层要分开治，混在一个 `wall_trim` 里就是现在"−20 还不够"的样子。

### 4.2 方案：引擎里立一个"实际位姿"，三类消费者各读各的

**一条原则**：
> 压在面上的脚按**指令位姿**发指令（那是弹簧的锚，改指令 = 改力）；
> 悬空的脚按**实际位姿**发指令（它没受力，发哪到哪）；
> 所有"碰不碰、正不正、够不够长"的检查按**实际位姿**下的真实构型算。

具体：

1. **引擎新增 `pose_real`**，与 `pose`（指令）并存：`pose_real = law(pose) + corr`。
   - `law`：按模式（摩擦 / 吸附）各一组系数：俯仰 = a×指令 + b，zb = c + d×指令俯仰，x 偏 = e（起步值：a 0.891、b −3°、c −21.5、d 按 16° 时 −40 反推 ≈ −1.2 mm/°、e 0）。
   - `corr`：操作者在检查点量了 F 高度后键入（新键 `m`：输 h_L1、h_L3、前 F 到墙），引擎算出 (x, zb, 俯仰) 与 law 的差存起来，之后 law 变 corr 不变。`d` 键已经是这个做法的先例。
   - 以后装了 IMU，俯仰/横滚这两项直接用传感器代替 law。
2. **悬空脚（悬停、落点、重放、收腿）按 `pose_real` 求身体系目标**：墙面悬停自动停在真实的 15 mm、落点高度自动补沉降。这一条直接替掉"`,`×10 + `+`×6"和 `wall_trim` 里的刚体部分。
3. **可行性检查两边都查**：指令构型查舵机行程 / IK 有解（命令必须发得出去）；真实构型（`pose_real` + 脚钉在面上反解）查 femur 离地、膝/腹面净空、吸盘倾角、伸直余量。09-13 "+9 时腿已贴伸直极限而模型还允许"和"后腿 femur 着地"都是真实构型查出来的事。`FEMUR_SAG_MM_PER_DEG` 删掉。
4. **提示按真实构型算**：`cup_tilt`、`floor_upright`、`wall_perp` 读 `pose_real`，屏幕角度才和眼睛一致；逐腿 `tilt_trim` 留着只吸收真正逐腿的残差（应该从 8° 掉回 2~3°）。
5. **`↑` 和 `--pitch-max` 改成真实度数**：要真实 2° 就命令 2/0.891；目标真实 60~70° 对应指令 71~82°，指令侧 IK 可能先到头，干跑加上 law 就能看出来，该补机身高度就补（`--auto-adjust` 已有）。
6. **偏航**：就位暂停时多量一个数（两前腿 F 到墙各一次），引擎算偏航后把两前脚的 `wall_trim` 自动填成 ±63·sinψ；或者更彻底，墙面作为带偏航的平面（引擎的 `Surface` 本来就是任意平面）。先做前者。

不做的：
- **全刚度模型**（按载荷分配算每腿让位）：六腿超静定、逐腿刚度差 4 倍、摩擦接触切向力未知，模型误差会和沉降本身一样大。等有实测位姿后再拿它做检查点之间的插值也不迟。
- **继续加常数**：`FEMUR_SAG`、"−16 是沉降"提示、`wall_trim` 上限 −60 这类，方案落地后都收掉。
- **z / x 上传感器**：地面和墙都是玻璃，光学测距不可靠；超声在大俯仰下掠射无回波。用尺 + law + 眼睛。

### 4.3 硬件：只推荐一件

**MPU6050**（I2C，几块钱）贴机身：静态俯仰 ±0.5°，顺带横滚（09-13 第 7 步"机身扭曲"就是横滚，现在只能目测）。在引擎主循环里读，别另起进程抢 I2C（ADS1115 那次的教训）。这一件把 law 里最不稳的俯仰项换成实测，z 项用一次 `m` 键标的 corr 就够撑一次实验。

### 4.4 工况上少让位（不用改代码）

让位 ∝ 关节力矩 ∝ 髋足距离：脚收到髋下（用户原则已经在这么做，22° 时 177→140 让 femur 扭矩降三成）；步小、勤重放本身就是在把误差清零。长期（P6）：舵盘/支架换金属、tibia 加筋。

| `>` `<` | 眼睛看着比屏幕斜就 `>`，一次 2°，然后 `v`。墙面脚门槛 25°，波纹贴平后杆斜十几度看不出，一般不用 |

中腿 L2 / R2（`2` / `5` 选中）：

| 键 | 做什么 |
|---|---|
| `v` | 提示 `2 v` / `5 v` 时按：抬起、摆到当前姿态下吸盘最正的地面点（会转 coxa，最多 ±55°），**自动落下** |
| `h` | 提示 `2 h` / `5 h` 时按（中腿最正也超 25°）：抬起收到髋旁悬空，从此不承重，只剩四脚 |
| `>` `<` | 站着时吸盘看着往外斜就 `>`（一次 2°，每 2° 往身体收 4 mm），然后 `v`。屏幕打下次该带的 `--tilt-trim`，带上就不用再按 |

后腿 L3 / R3（`3` / `6` 选中）：

| 键 | 做什么 |
|---|---|
| `b` | 抬起，摆到髋正后方的地面点（coxa 转到指正后，离髋 = `--rear-dist`，没给取站位半径，带 `--tilt-trim L3:8` 时是 160），悬停 |
| `i` | 落下、压入、回支撑。`b` 之后必须按 |
| `v` | 提示 `3 v` / `6 v` 时按：抬起、摆到最正的地面点，自动落下。抬头越高它越往身体收 |
| `>` `<` | 同中腿 |

后腿到不了的：`w` 要到指令 72.5° 后髋才够高，之前按了打"无可落足带"；干跑停在 60° 是后腿 femur 离地不够，`v` 救不了，靠 `--auto-adjust` 抬机身，抬到头就到头。

机身：

| 键 | 做什么 |
|---|---|
| `↑` `↓` | 抬头 / 低头 `--pitch-step`（2°）。开了 `--auto-adjust`，`↑` 被几何原因拒时自动试"升高 0~30 mm、前后 ±15 mm"配合抬头，补不了才打"自动补高度/前后也不行" |
| `←` `→` | 机身离墙 / 贴墙 5 mm，脚钉在原地 |
| `[` `]` | 机身降 / 升 5 mm，脚钉在原地 |
| 空格 | 机身正在动时按：停在半路（每个中间位姿都预检过，停哪都安全） |

流程与安全：

| 键 | 做什么 |
|---|---|
| `d` | 就位暂停时：输入卷尺量到的前腿 coxa 轴到玻璃的水平距离 |
| `p` | 就位暂停时：开始逐足压入的启动序列 |
| `f` | 全机冻结后解冻；在途的交接不取消，位姿铺设取消 |
| `o`×2 | 取机：停泵、逐足放气、舵机断电。**先托住机身** |
| `ESC`×2 | 退出并给舵机断电，机身会塌，先托住 |

常用参数：`--wall-suck`（地面只压、墙面抽气）、`--attach-kpa`（−60）、`--suck-timeout`（6 s）、`--wall-dist`、`--wall-height`、`--rear-dist`、`--fwd-dist`、`--fwd-reach`、`--floor-clear`（上限 120）、`--support-legs`、`--support-tilt`（35）、`--tilt-warn`（10）、`--wall-tilt`（25，旧名 `--wall-tilt-warn` 仍可用）、`--tuck-tilt`（25）、`--tilt-trim`（逐腿 ±15 / 全局 ±8）、`--wall-trim`、`--auto-adjust`、`--pitch-step`、`--pitch-max`、`--press-delta`、`--handover`/`--takeover`（吸附路线）、`--dry`/`--mock`/`--no-tank`。

阀线圈由引擎驱动（所有模式一样）：站着断电、摆动通电、某脚抽气前把其余盘通电隔离、吸住断回；`--dry` 的真阀镜像仿真气路上的阀位。状态行 `阀电 L2L3R2R3` 列出此刻通电的腿。
