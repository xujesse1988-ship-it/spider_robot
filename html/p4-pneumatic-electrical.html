丝印读到之后，仍要量的三处（通断档，断电、板上不接任何东西，合计一分钟）
  1. DC+ 与 8 个 OUTn+ 是否导通。应导通——这是本板"每通道只切「−」侧"的低边开关结构，也是阀两根线直接跨 OUTn+ / OUTn− 就能工作（不必另拉 12V）与泵必须绕开 OUTn+（否则泵会被并回阀轨，分轨失效）这两条接法的前提。若不导通，说明每通道的「+」是独立端子，那就把阀的「+」自己接到 12V-V，泵接法不变。
  2. IN1− ~ IN8− 之间是否互通。互通 → 8 根 GPIO 线 + 1~2 根地线回 Pi 即可；不互通（每通道独立隔离输入，本板很可能是这种）→ 在端子上用短跳线把 8 个 IN− 并成一条信号地母线，再用 2 根线回 Pi Pin34/39。别用 16 根线单独回 Pi，那是 8 个地环。
  3. IN− 与 DC− 是否导通。光耦板通常不导通 = 真隔离，此时按图 4"两侧地各回各的源"接，不要人为把它们连起来。若导通，则板本身就是单点共地，Pi 与 12V 之间不得再拉第二根地线。
IN1~IN8 ↔ 阀/泵 的分配沿用 p4-pi-wiring.html：IN1=阀 L1（GPIO5）、IN7=泵 A（GPIO20）是 P1 已实装的两路，其余六路 P4 定案。改分配就同步改 adhesion.py 的 VALVE_PINS / PUMP_PIN。

与既有文档的三处有意差异（本图是端子级落地，遇到冲突以本图为准，并请回填 P4-BAY-DESIGN）
  1. 双轨供电：p4-system-diagram.html 与 P4-BAY-DESIGN §2.2 画的是"XL6009 ×2 并排 → MOSFET 板电源入"，读起来像两块并联同一条 12V。升压模块不能直接并联（输出电压不可能完全一致，高的那块独扛全部负载，另一块空转甚至倒灌）。本图改为 #1 专供泵、#2 专供板 DC+（阀由板内 OUTn+ 母线取电），两块各自独立，只共功率地。舱内布局不用改——两块仍并排，只是出线各走各的。
  2. 泵「+」不经板 DC+，OUT7+ / OUT8+ 空置：背面丝印显示每通道有独立的 OUTn+ / OUTn−，而 OUTn+ 内部并在 DC+ 上。所以阀最省事——两根线跨 OUTn+ / OUTn− 就完事；泵反过来，必须让 OUT7+/OUT8+ 空着、「+」单独吃泵轨，否则两条轨在板内被 DC+ 母线短接，分轨就白分了。这是分轨能成立的前提，也是接线时唯一容易接错的地方。
  3. INn± 之间 10k + 5A 保险：两项既有文档没有的新增件。板的输入是 8 组光耦隔离对（INn+ / INn−），10k 就跨在同一路的这两个端子上，为 GPIO5/6 的复位默认上拉兜底（见图 3 footnote）；保险是 2S 锂电短路能量决定的——XT60 之后、升压之前那一段是全机唯一没有任何限流的地方。
装配与检验清单（按顺序做，每步不过不进入下一步）
  1. 板未上机先量三处：图 2 note 的三条（DC+↔OUTn+ 是否通、IN− 之间是否通、IN− 与 DC− 是否隔离）。结果决定阀的接法、信号地的并法、以及图 4 那根跨接线接不接。
  2. 两块 XL6009 空载调压：各自单独接电池、空载把电位器调到 12.0V，断电、标记"#1 泵轨 / #2 阀轨"后再接负载。两块调完互不再动。
  3. 先接控制、不接负载：Pi ↔ IN1+~IN8+ + 并好的 IN− 信号地 + 8 只 10k。Pi 断电状态量每路 INn+ 对 INn− <0.8V；Pi 上电但程序未跑时复量一次，仍 <0.8V 才算过。
  4. 空载点动：接 12V、不接阀泵，逐路 GPIO 点动，看 LED 与 OUTn− 对 OUTn+ 的电压翻转（关断 ≈12V、导通 ≈0V）。八路全通过再接负载。
  5. 负载逐路上：先上 6 阀（听咔哒、同时确认气路方向：断电时吸盘通真空、通电时通大气），再上 2 泵。每上一路复查一次总电流。
  6. 断电保压实测：整机吸附状态下直接拉总开关，六足应全部保持吸附 ≥60s（这是 VALVE_ON_LEVEL=0 接法的全部意义）。此项不过，禁止上墙。
  7. 传感链最后接：i2cdetect -y 1 见 0x48/0x49；7 只传感器悬空置于大气，读数应一致 ≈0.25V。泵开机再读一遍，7 路读数抖动 <±1kPa 才说明分梳走线到位。
  8. 全部通过后 vcgencmd get_throttled 复查 0x0，并把实测电流、端子位、GPIO 映射回填本页与 adhesion.py。
