# 地-墙过渡 · 摩擦上墙前期（泵不开）

> 目的：泵不开，六条腿只压不吸，看不抽气能抬多高、滑不滑。
> 规则只有一条（09-13 定）：**在地上的脚，吸盘轴尽量垂直地面；斜了就抬起重放到最正的点，需要转 coxa 就转；步子小、多迈几步。**
> 脚压在地上是滑不动的，所以"贴地随动"作废，所有挪脚都是抬起 → 摆过去 → 落下。
> 屏幕会告诉你哪只脚该重放（`v`）、哪只中腿该收起（`h`），照着按就行。
> 干跑（模型）走到指令 60°；实机比模型斜，走到哪算哪，量出真实角度和机身下沉，回来修引擎。
> 当前问题与方案在 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md)；历次版本的原因分析、干跑数据、实机记录在 [WALL-MOUNT-HISTORY.md](WALL-MOUNT-HISTORY.md) §4.7。跑之前先 `git pull`。

## 1. 准备

1. 气管照常接着；地面、墙面玻璃擦干净、擦干。
2. 安全绳绷紧、留够长度（机身会升到离地 20 cm 以上）；人站侧面，手随时能托住机身。
3. 站位：前腿 coxa 舵机轴离墙 135~142 mm，就位暂停时按 `d` 填量到的数。
4. 白板笔：每只脚放好后沿吸盘边画一道短线（地面脚画后边，墙面脚画下边），滑没滑看它。
5. 手机固定在机器人左侧，和机身同高、正对着；钢尺。

## 2. 命令

```bash
python scripts/mount_wall.py --dry --support-legs L1,R1,L2,R2,L3,R3 \
    --auto-adjust --wall-dist 140 --pitch-step 2 --pitch-max 70 --floor-clear 100 \
    --handover L1:10,R1:10
```

`--handover L1:10,R1:10` 是零力交接（09-13 晚加）：前腿抬起前先把它的力卸到零、其余五条腿各多压 2 mm，抬腿那一下机身不再往前塌。
状态行里该腿先 `Z` 再 `V`、`L`；落定后 `z` 还账。**只给前腿**：后腿、中腿落地会把欠账压到自己身上（18+δ），离压深上限 28 太近，给了会在 42° 前后把收中腿卡死（干跑 60° → 48°）。
不再带 `--slide-legs`。`--tilt-warn 10`（超过就提示重放）、`--tuck-tilt 25`（中腿最正也超过就提示收起）是默认值，实机觉得 10° 还太斜就改小。

**站着时中腿吸盘就不垂直（往外斜）**：加 `--tilt-trim L2:6,R2:6`。这是告诉程序"这两条腿的吸盘轴实际比模型算的向外斜 6°"，
程序会把它们的站位往身体收（每 1° 约 2 mm，6° 收 12 mm），之后 `v` 的最正点、提示也都按这个算。先试 6，站起来看中腿吸盘还斜就加到 8、10；
别的腿也斜就一起写，比如 `L2:8,R2:8,L3:3,R3:3`。
泵不转，屏幕上的盘压、罐压、泵开停、"吸附完成"都是仿真的，不用看。阀是真的：抬腿前先通电放气 0.3 s。

## 3. 步骤

**上一个动作做完再按下一个键**：机身动完打"位姿铺完"，腿放好打"收口"。这两行之后屏幕紧接着打一行
`⚠ 该重放：…` 或 `各脚离面法线都 ≤ 10°`，照它按。状态行末尾 `轴 L1:3 L2:12! …` 是每只脚吸盘轴离面法线的角度，带 `!` 的就是该重放的。

| # | 按键 | 看什么 |
|---|---|---|
| 1 | 就位暂停：量距 → `d` 填 → `p` | 六个脚压到位 |
| 2 | `1 w i`，`4 w i` | 两前足上墙，吸盘压上玻璃没有 |
| 3 | `3 b i`，`6 b i` | 后足指向正后（和身体平行），吸盘轴垂直地面 |
| 4 | `↑` | 抬 2°，等"位姿铺完"和提示 |
| 5 | 提示有 `n v` 就按 `n v`（n = 腿号）。地面脚会自己落下；前脚会悬停，目测离玻璃约 15 mm（`.` `,` 调）再按 `i` | "收口"和新角度 |
| 6 | 提示有 `n h` 就按 `n h`（收起中腿，从此只剩 4 个脚，盯紧笔线） | |
| 7 | 回到第 4 行，直到 `↑` 打出 `位姿拒绝（抬头 2°，自动补高度/前后也不行）` 而且提示里没有可按的键 | |
| 8 | 静置 30 s；记电流，钢尺量后腿 femur 最低处离地、L1 和 L3 的 F 点离地、前足吸盘离地，拍侧面照 | |
| 9 | **先托住机身** → `o`×2 → 抱下来 → `ESC`×2 | `ESC`×2 会给舵机断电 |

`v` 被拒（"落点不可行 / 路径不可行"）不用管，继续 `↑`，下一档再按。一次提示里有几只脚就按几只，先中腿后后腿再前脚。
每个键对谁有效、什么时候能按、按了发生什么，全表在 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md) §5。

**眼睛和屏幕不一致时，以眼睛为准**：
- 屏幕说某只脚正、眼睛看着斜（09-13 实机：后腿）：选那条腿按 `>`，意思是"它实际比算的向外斜 2°"，状态行里它的角度会涨；看着斜得多就多按几次，然后按 `v` 重放（每 2° 往身体收约 4 mm）。屏幕会打一行 `下次启动用 --tilt-trim L3:6,R3:6`，下次带上就不用再按。
- 屏幕说斜、眼睛看着正（09-13 实机：前脚 L1 算 21° 实际仍垂直）：不用理。前脚吸盘的波纹贴平玻璃后杆斜十几度看不出，所以墙面脚的门槛已放宽到 25°（`--wall-tilt-warn`）。

干跑参考（站位 140，模型，实机会不一样）：

| 抬到 | 提示会让你按 |
|---|---|
| 4° | `1 v i`、`4 v i`（前脚上挪到离地 232） |
| 12° | `2 v`、`5 v`（中腿转 coxa 55° 重放，12°→7°） |
| 18° | `1 v i`、`4 v i`（267） |
| 22~24° | `5 v`、`2 v`（中腿 16~20°→12~13°）；`3 v`、`6 v`（后腿仍指正后、收近一点，15°→1°）；`1 v i`、`4 v i`（300） |
| 32° | `1 v i`、`4 v i`（335） |
| 42° | `2 h`、`5 h`（中腿最正也 26°，收起）；`1 v i`、`4 v i`（345） |
| 46° | `1 v i`、`4 v i`（350） |
| 60° | `↑` 被拒：后腿 femur 离地不够，`v` 也救不了，到头（共 ↑ 30 次、抬脚 22 次） |

## 4. 什么时候停

出现下面任何一条：手托住机身（机身正在动就先按 `空格`，停在半路），记下几度、哪只脚。

- 任何吸盘离开笔线 3 mm 以上，或者还在慢慢挪。
- 抬腿时机身往那边歪、吸盘粘着玻璃不走，或腿抬空了还蹭地。
- 某只脚看着比屏幕上的角度斜得多（机身压弯了腿）。
- 后腿 femur 离地不到 1 cm，或腿、膝、机身互相碰到。
- 电流持续超过 5 A，或舵机摸着烫手。
- 屏幕打 `⚠⚠⚠ 全机冻结`。

## 5. 记录

每次 `v` / `h` 之后填一行，没事的格子空着：

| 抬到 | 按了什么 | 电流 A | 屏幕角度（前/后） | 目测斜不斜 | 滑了吗（哪只脚、往哪、几 mm） |
|---|---|---|---|---|---|
| | | | | | |

终点另记：后腿 femur 离地、L1 / L3 的 F 点离地、前足吸盘离地、侧面照。
交接有没有用看两处：`1 w i` 做完、`4 w i` 做完各量一次 L1、L3 的 F 离地（或看笔线），和没开交接那次比（吸附路线的口径是 9 → 5、15 → 5 mm）。
日志（`software/logs/mount_*.log`，提示、拒绝原话、⚠ 行都在里面）和照片传到开发机（`64.176.60.202`）。

## 6. 判据

- **走到 `↑` 被拒、静置 30 s 不滑**：不抽气这段成立。按量的数修引擎（机身真实沉了多少、femur 余量对不对），再接抽气段。
- **某次 `v` 之后那只脚滑**：重放的落点不对，把那一行记录发我。
- **中腿收起后滑**：后足往后滑 → 地面后足改成抽气吸住；前足沿墙下滑 → 墙上提前抽气。
- **屏幕说 ≤ 10° 但眼睛看着明显斜**：机身压弯了腿，实机比模型斜；`--tilt-warn` 改小（8、6）再跑，并把量的数发我。
