Zero-force handover + rotation weights: n=3 Latin-square wall experiment, main results (2026-08-25/26)

Three replicates × three conditions (A baseline / B δ calibration table / C = B + weights), run order rotated as a Latin square (#1 A→B→C, #2 B→C→A, #3 C→A→B — each condition appears exactly once in each slot, so order/voltage effects are decoupled). Single-replicate details: html/en/handover-ab-20260825.html. Protocol: docs/en/HANDOVER-AB-PROTOCOL.md. Each run = one body_lean key press t (marker + automatic 3 rounds × 6 legs + tail rest); the automation keeps the timing identical from run to run; all nine logs show zero freezes / zero truncations / zero threshold waits.

4. Two new findings (confirmed by n=3 reproduction)

Finding 1: the main battlefield of the residual slip is the handover apportioning segment, concentrated in the stiffest legs L1/R1 and growing round by round — reproduced in all three replicates.
Group B L1 handover segment per round: #1 6.8→10.3→12.6, #2 6.9→8.6→10.6, #3 6.7→8.8→11.9 mm (R1 similar, 6.6–11.4); the other four legs ≈0–1.5 mm. Mechanism: "six-leg command mean unchanged ⇒ body does not move" only holds for equal stiffness; the elastic equilibrium is a stiffness-weighted average, so unloading from the stiffest legs (slopes 0.57/0.39) necessarily lets the body sink. About 50–60% of the B/C residual is in this segment (B 56–58%, C 47–62%) — a next-generation "stiffness-aware share" (solving Σk·d=0) has ~60% headroom, and the three replicates give it an n=3 experimental basis.
Finding 2: command→actual compliance transfer ratio 42.2 ± 3.0% (9 independent markers, 3 days, 3 camera positions).
The ±10 mm sync markers measured a body displacement of 3.78–4.73 mm (A 4.15±0.36 / B 4.28±0.39 / C 4.22±0.27; the C2 marker was included after the deviation-① sync correction, and its fitted amplitude of 4.23 mm independently confirmed the new sync). Along the shear direction on the wall, about 60% of the commanded displacement is absorbed by leg-chain compliance; no systematic difference across conditions (handover/weights do not change the transfer ratio, which is reasonable — the marker is applied in the all-supported rest state).

5. Current accounting (cost of the method, n=3)

The handover trades impact slip for sustained servo load: current increase A +0.97 → B +2.40 (×2.5) → C +1.85 A (−23% vs. B). Spread across the three replicates ±0.08 A, extremely stable. Weights lowering the sustained load agrees in direction with the model (Appendix A steady-state internal stress −32%), at about 2/3 of the magnitude. Note: the nine runs started at 7.51–8.07 V; the Latin square decouples voltage from condition, so within-run trends are trustworthy.

6. Deviation log (to be reported honestly in the paper)

  • ① C2 (08-25 afternoon) sync correction (08-26): the original step-rescue locked onto the wrong comb tooth by one slot; re-anchored by the marker method. Recording started late, so the head of the marker window fell 2.3 s before the start of the video; the marker method's search bound "whole window inside the frame" (off≤57.7) excluded the true value and found a false peak (R²=0.60); the subsequent step-basis regression looked reliable (R²=0.9992), but in this run the intra-round spacing of the vent comb was highly periodic (17.5–18.5 s), teeth offset by one slot differ in R² by <0.001, and the B2 sub-second calibration could not tell the teeth apart — off=77.25 landed on the +1 tooth and the per-leg attribution shifted by one slot as a whole (a spurious "big R2/L2 drop"). Noticed on 08-26 because the per-leg handover pattern disagreed with C1/C3/B entirely; two independent anchors fix the true tooth: ① the marker was in fact captured in the head of the video (the y swing of ~14 px at the mapped 0.7/3.7 s matches); ② under the +1 tooth the closing 6 vents of the shutdown map onto a completely flat segment (physically impossible). A marker-shape fit allowing window clipping gives off=59.34 s (R²=0.99), fitted amplitude 4.23 mm = transfer ratio 42.3%, independently cross-checked by the other 8 markers at 42.2±3.3%; C2 is thereby upgraded to a marker sync on the same footing as the other eight runs, and the report was regenerated with the new off (old table kept as report_off77.25_mistooth.txt). Total is conserved (70.2→70.5 mm) and per-round values unchanged; the correction only affects the handover/vent split and the per-leg attribution (C handover segment 38.7±5.0→39.7±4.3, vent 21.3±5.2→20.1±3.3, SD tightened). Lesson: check comb periodicity before a step rescue; "marker not captured" must distinguish a fully missing segment from edge clipping — the latter can be fitted with a clipped window (tool marker_off_clip.py).
  • The camera moved between #1 A→B and #2 C→A (tens of px); #3 was stable within ≤0.4 px in-session: scale per run from the measured board long edge (0.2883–0.2957, ±0.2–0.5%), in-run drift corrected by the static ref object — resolved, does not affect the conclusions.
  • Battery: first run of each session ≥7.88 V (#2/#3 first runs ≥8.06 V), declining within a session to ~7.5–7.7 V, not recharged between runs; after Latin-square decoupling no visible voltage confounding.
  • Median body_score 0.39–0.76, below the internal 0.8 convention (board tilted 4–31° + fine 4K texture pulls the axis-aligned NCC score down); ref 0.988–0.999, cross-validation of the nine runs CV 1.6–4%, so the structure of the results is trustworthy. Improvement item: rotation-tolerant templates.
  • #3 video stabilization shows 3–5 px of slight distortion in the upper part of the frame (~1.5–2 px at board height); the ref was chosen as a static object in the lower part of the frame to avoid it.

7. Conclusions

n=3 Latin-square main result: the zero-force handover reduces three-round total slip 185.5→105.6 mm (−43%, p=0.0013), and adding rotation weights → 72.9 mm (−61%, p=0.00092; −32.7 mm vs. B, p=0.0022); ratchet displacement at the rupture instant −82%/−88%. Per-replicate relative effects vary by ≤3 percentage points; the paper's main table is complete.
