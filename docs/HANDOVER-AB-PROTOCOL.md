## 1. 目的与总判据

重跑 08-20 原地踏步实验（同工况同节奏），对照 `--handover` 起标表开/关：

| 指标 | 基线（08-20 实测） | 达标线 |
|---|---|---|
| 每轮下滑（第 2 轮） | 74mm（本管线口径 76.4） | **<10mm/轮**（降一个数量级） |
| vent 跳变逐腿（第 2 轮） | L1 20.9 … L2 5.8mm | **逐腿 \|x\| ≤ 2mm**，无可见弹跳 |
| 整机电流 | 静置 0.79A → 逐周期爬至 ~1.8A 不回落 | **结束静置 ≤ 首抬前 +0.2A**，无逐周期爬升 |
| 交接段身体位移（新增机理检查） | —（基线无此段） | **\|x\| ≤ 3mm 且平滑无台阶**（均值不变的实机验证） |

第 4 条是机构正确性的独立探针：交接期间六腿指令均值不变 ⇒ 身体理应纹丝
不动。若交接段身体系统性下坠 ⇒ 方向/分摊有 bug 或 δ 严重超标，**当场停**。
⚠ 逐腿 δ 表的已知伪迹（设计 §2 ⚠ 注，审核实测）：落地复位吞掉交接残差，
六腿指令均值每次落地跳一步——B 组首轮会累计 ~5mm **上坡**指令伪迹（即首轮
下滑读数比物理真实少 ~5mm）、轮内 ±1.3mm 摆动。这属于表非均匀的几何账，
**不是**分摊 bug：方向是上坡、量有界、第 2 轮起每轮漂移归 0。"当场停"只
认**系统性下坠**；上坡侧的小台阶按伪迹放行。

## 2. 工况与命令行（照抄基线，只差 --handover）

```

python scripts/body_lean.py --no-tank --stand-height 62 --tilt-trim 6

# B 组（零力交接，δ 起标表 = 实测弹跳×0.8）
python scripts/body_lean.py --no-tank --stand-height 62 --tilt-trim 6 \
    --handover L1:17,R1:15,L3:11,R3:9,R2:5,L2:5
```

同一面玻璃墙、尽量同一位置；A/B 各自完整"上墙-实验-取下"，中间**不碰相机**。

为什么还要跑 A（08-20 已有基线）：①当日在场对照排除玻璃洁净度/电池/温度
差异；②B 组全程位移 <10mm，**mm/px 比例只能由 A 组的大位移标定**、B 组
沿用（所以相机 A→B 锁死不动是硬要求）；③A 第 2 轮逐腿弹跳若与 08-20 偏差
>20%，δ 表按当日值 ×0.8 重标再跑 B。

5. 结束静置 ≥30s（电流回落观测窗；自动序列已含）→ 扶稳机身 → `ESC`×2

## 6. 判定与 δ 修正规则

先看 §1 四条。分支处理：

- **第 1 轮早腿轻微上弹（-1~-3mm）= 预期，不动 δ**。1-D 模型：交接稳态
  下每次抬腿的储能与基线稳态相等（δ 按基线弹跳标对稳态是对的），但首轮
  储能从 mg/6k 爬坡到稳态（模型 14.8→36.9，基线实测 vent 跳变第 1 轮
  2.3→16.3mm 同款斜坡）——首轮早腿必然轻度过冲。**判定一律看第 2 轮**。
  另：逐腿 δ 表的落地复位伪迹（§1 判据 4 ⚠ 注）会让 B 首轮下滑读数比物理
  真实**少 ~5mm**——首轮数字偏好看属预期，同样不作数。
- **交接被引擎截断的抬落不进 δ 修正**：脚本打出"⚠ 交接越界截断"（黑匣子
  同记）说明该次 δ 没铺满、弹跳必然偏大——那是工作空间账（步幅/漂移）的
  问题不是 δ 不够，按残余加 δ 会火上浇油。有效 A/B 组内截断次数应为 0，
  出现即先查步幅/站位再重跑该组。
- 第 2 轮某腿残余下坠 >3mm：δ_i ← min(δ_i + 0.8×残余/|斜率_i|, 45)。
  斜率_i 取该腿"弹跳 vs δ"实测斜率（08-24：L1 0.57/R1 0.39/L3 0.21/
  R3 0.25/R2 0.13/L2 0.14）；没有斜率数据时保守用 0.8×残余×5（均匀刚度
  近似）。旧钳位 21 是"弹跳当储能"的错账（设计 §5 ⚠），已随解析上限
  25→45 一并废止；
- 第 2 轮某腿上弹 <-2mm：δ_i ← δ_i − 0.8×|上弹|；
- 改表后整组重跑 B'（重新上墙）；一个下午预算 A + B + B' 三组
  （每组墙上 ~10min + 换装 ~3min）。
- **当场停**的情形：交接段身体系统性下坠（机理 bug，回桌复查 4.7 步方向
  /分摊）；任一腿上弹 >5mm（δ 严重超标，全表减半重试）；第 1 轮下滑
  不降反升（方向反了级别的错误）。
- 冻结处理照旧：交接中支撑腿**或交接腿本身**漏气都会自动暂停（v1.6 起
  交接腿纳入监护；Z 段变长属正常），挽救超时冻结按 `f` 续铺；
  `clear_freeze` 不丢在途交接（tests §7.6 已固化）。

达标后的推进（设计 §9.4）：climb_walk 先单步（`i`）后连续，δ 微调，重测
净前进率（26% 基线）——ab_quant 现已直接解析 climb_walk 日志（单步/连续
混跑都行，从相位转移行建时间线；退出序列的放气会被滤掉不计入抬落——
08-19 climb 日志真实抬落是 10 次，按 vent 事件数数出的 16 是错的）；
δ 标稳后可另开一组 `--handover-weights`（载荷按窗序
轮转距离加权，设计 §5 v1.5；口径假设按"轮到 X"提示轮转抬腿）A/B——模型预期循环内应力降 ~30%、δ 表随之整体
下调重标，务必与 δ 标定分开成组，别混变量；报告并入 html（管线输出直接喂
`vent-snap-20260820.html` 同款图表）。**A/B 期间 --sag-comp 保持 0**
（两者同开双份推挤支撑系，设计 §4.3）。

## 8. 双足（--dual）标定与 A/B 增补（DUAL-SWING-DESIGN §6，2026-08-24）

双足=双摆动窗（duty 4/6，恒 2 腿在摆/4 足吸附）。**δ 表不与单足互通**：
接住方 5→4 弹跳读数 ×5/4、稳态储能变（静载份额 mg/5→mg/4、3 窗节奏），
预计 δ*_pair 较单足上移 +10~30%。斜率也随接住数变，一并重取。

### 8.1 双足 δ 三组标定（body_lean --dual 原地对抬）

```
# 三组 = 单足现表 ×0.5 / ×0.75 / ×1.0（不从 δ=0 起：双足裸弹跳更疼，
# 线性外推本就不需要零点。单足现表=08-24 δ*×0.8：L1:31,R1:33,L3:29,
# R3:22,R2:22,L2:24）
python scripts/body_lean.py --no-tank --stand-height 62 --tilt-trim 6 --dual \
    --handover L1:16,R1:17,L3:15,R3:11,R2:11,L2:12     # ×0.5 组
...  --handover L1:23,R1:25,L3:22,R3:17,R2:17,L2:18    # ×0.75 组
...  --handover L1:31,R1:33,L3:29,R3:22,R2:22,L2:24    # ×1.0 组
```

- 键序：`p` 启动 → **一键 `t`（§4.3：对时标记+自动轮换，双足下自动逐对
  对抬、每轮 3 对，对序按环序由引擎轮次保证；对时标记不许跳过——08-24
  三组对时全错的教训：活动对比度对时对准周期节奏错整数格照样得高分）**。
  手动备选：对时标记后数字键选对
  首腿 → `i` 对抬（对内两腿先后 0.6s 悬停）→ 两腿都悬停后 `i` 一并落地
  （错峰下探）。对序按环序轮转：L1+R2 → L3+R1 → L2+R3。
- **每组 ≥2 整圈（3 对/圈），首圈弃**：冷启动首窗只有单摆、分摊落在 5
  支撑，与稳态 4 支撑不同工况（单足协议"看第 2 轮"的同款纪律）。
- 引擎放气错峰 ≥0.4s（对内窗头差 + 守卫）：30fps 下两次破裂相距 ≥12 帧，
  逐腿 vent 跳变照旧可分辨——量化管线口径不变。
- 逐腿线性外推 δ*_pair → **×0.8 起标**。δ*_pair 顶破解析上限 45 的腿：
  第一救济=开权重（下条，模型 δ* 相应下移）；仍顶帽再按拍板 C 记实测值、
  按 room 账（comp_tail−半步幅）议抬上限，不预支。
- **权重（v1.1 起双足可同开，08-24）**：若上墙口径打算开
  `--handover-weights`（单足实测对下滑改善明显），δ_pair 三组**按开权重
  工况跑**（权重改变稳态运行点，δ 表跟工况走）。双足档=不带值自动取
  **1,1,1,0,0**（刚落的对+次对后腿三等分；份额按轮转距离取值+就地归一，
  模型最差单腿 −12%/均值 −21%，DUAL-SWING-DESIGN 附录 C）；**勿搬单足
  激进档**（模型：对内后腿被推高过均分 32.9>30.8）。权重生效前提=对序
  按环序轮转（本节键序本就如此）；偏离轮转的对被引擎守卫退回均分并提示
  ——标定录里见到守卫提示说明键序乱了，该组作废重跑。
- ab_quant：对步第二只腿经落地错峰队列走 hover→descend，解析已补该

### 8.2 双足 vs 单足行走 A/B（climb_walk）

同参数各跑一段连续直行（`--dual` 唯一差异；δ 各用各的表——单足用单足
表、双足用 8.1 标出的表，**这不是混变量**：δ 是各口径的正确运行点）：

| 指标 | 说明 |
|---|---|
| 净前进率 mm/s | 总判据：双足达标线 ≥1.8× 单足（理论 ~2.5×） |
| 每米密封破裂事件数 | 理论 −20%/米（6 事件/48mm → /60mm） |
| 每事件位移 | 双足接住方 4 腿，同残余 δ 缺口读数 ×5/4——不劣于单足同 δ 档即过 |
| 电流棘轮斜率 | 腿间内应力累积探针；4 支撑基线整体 +25% 属静载份额，看斜率不看绝对值 |
| 最差盘压分布 / 门槛等待计数 | 泵跟不跟得上双倍每窗新盘（真罐模式重点盯；后手=泵 B） |

⚠ 双足全程绳保护（支撑冗余降一档：单盘漏气瞬间=3 足承载=设计"极端保守"
线）；`--sag-comp` 在双足下被脚本拒绝（拍板 B）；`--handover-weights`
v1.1 起可同开（双足档 1,1,1,0,0）——变量纪律：权重开关自成 A/B 组，
勿与 δ 档、单双足口径混在一组里比。

## 9. D′：交接铺设速率判别实验（2026-08-26 立项，T1 拟合的直接后续）

**缘起**（html/stiffness-fit-20260826.html）：n=3 的 B/C 交接段拟合显示
~九成损失是"每窗共模下沉≈蠕变率×窗时长"（B 60.2=再分配 6.7+共模 55.5；
C 39.7=7.7+30.0），刚度感知份额只能动再分配项（收益 3~4mm，原 D 设计
按门控否决）。窗时长≈0.5+δ/rate 与 δ 完全共线 ⇒ "时间蠕变"与"逐 mm
损耗"离线不可辨——**改铺设速率是唯一判别手段，且若时间蠕变成立顺手
白捡 ~12mm**。

**工况**（C 复刻 + 唯一新变量 `--handover-rate 20`）：

```
# C 组（对照，08-25/26 口径原样）
python scripts/body_lean.py --no-tank --stand-height 62 --tilt-trim 6 \
    --handover L1:31,R1:33,L3:29,R3:22,R2:22,L2:24 --handover-weights

# D′ 组（唯一差异：铺设 10→20mm/s；δ 表/权重/其余全同）

    --handover L1:31,R1:33,L3:29,R3:22,R2:22,L2:24 --handover-weights \

```

**设计**：同日配对 ≥3 对、顺序交替（C→D′ / D′→C / C→D′），统计口径与
n=3 主表同档；每组 body_lean 一键 t（60s 起跑静置已内建——录像开着即可
按 t，§4 第 2 步）；电池 ≥8.0V、三脚架组间不碰、比例逐组板长边。

**判读**（量化 ab_quant 照常，逐腿交接段进 fit_stiffness 复跑）：

| 结果 | 判定 | 后续 |

| D′ 交接段 ≈ 按窗时长比例降（39.7→~25mm/组，C 总 ~72.9→~58） | 时间蠕变实锤 | 蠕变定律进论文模型节；可试 30mm/s 再压一档（仍 ≤50 护栏，动态风险自评） |
