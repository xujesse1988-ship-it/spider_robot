# P4 可拆器件舱 V1

本目录由 `tools/generate_p4_bay_v1.py` 生成。V1 保留 V0 的 190 × 130 mm
外廓和原车架 `(±44, ±40)` 四孔，但重新设计下层器件安装、100 mm 电气夹层
和线束出口。V0 目录没有被覆盖。

## 生成与验证

```bash
venv/bin/python tools/generate_p4_bay_v1.py
venv/bin/python tools/validate_p4_bay_v1.py
```

当前校验结果为 **22 passed, 0 failed**：

- 恰好 13 个 STL，全部水密、单连通体、正体积；
- 21 个已定位打印件实例无正体积碰撞；
- 41 条选定螺钉通路同时贯通模块和承载件；
- 7 块 PCB 外廓、同面间距以及 10 个端子/弯线服务区合格；
- 7 个传感器下向针脚通道、6 个阀下向塑料嘴通道均贯通。

`layout-report.json` 是装配坐标、板孔、接线服务区和验证输入的机器可读记录。

## 装配和连线方向

- 两台泵中心为 `(-46, 24)`、`(46, 24)`；泵支架与适配板之间放 TPU 垫。
- 阀轨中心为 `(0, -44.5)`。六只阀竖装，底部塑料嘴向下、侧嘴朝 `-Y`，
  阀轨中部不再用实体横梁封死气嘴。
- 传感器桥中心为 `(0, 12)`，桥板底面装配高度为 16 mm；针脚穿过桥板窗口，
  下方三条齐平横梁避开全部 7 个窗口。
- 歧管位于阀组后侧，减少六根阀管的交叉；泵管从两侧进入，不能压过阀线圈
  或传感器取压管。
- 电气甲板左侧走 GPIO、I²C/模拟传感器线，右侧走电池、泵和阀功率线；两类
  线束分别进入左右 cable comb，不共用束带。
- 顶面：分压汇接板在左、Pi 5 在中、5 V 降压板在右；底面：继电器在左，
  两块 XL6009 沿后缘，YYNMOS-8 在右前。板边保留端子起子和线弯空间。
- 泵和阀电流必须走继电器/MOSFET 与独立降压功率路径；Pi 只提供控制信号，
  不从 GPIO 引脚给泵、阀或继电器负载供电。

## 打印前仍须实测

自动校验只能证明当前尺寸代理之间不相撞，不能代替实物公差验证。正式打印
底板前仍须完成：

1. 用 fit template 在六腿全行程和实际线束状态下做慢速动态扫掠；
2. 复核 555 泵体相对 48 × 28 mm 支架孔中心的前后偏置；
3. 复核 0520B 两个塑料嘴的实际伸出量（V1 代理按 12 mm）；
4. 先各打印一个泵适配板、阀轨和传感器桥，确认孔径与压配间隙；
5. 储气罐到货前不生成抱箍，避免依据未知耳距制造。
