# P4 电气+气动舱固定件 · 设计方案

目标:把 P4 吸附系统的全部电气/气动器件收进**一个可整体拆下的"舱"**,
固定在 MakeYourPet 机身(frame)顶面,几颗 M3 下机。本文档只做设计与规划,
**不出 STL**——关键尺寸(§4)实测回填后,扩展 `tools/generate_climbing_parts.py`
一键生成(§5)。

依据材料:
- 实物照片 `dianqi.jpg`(器件安装特征盘点的第一手来源)
- 连接拓扑 `html/p4-system-diagram.html`(电气三路 + 真空母线,决定相对位置)
- `docs/P3-GUIDE.md` 第 2 步"P4 气动舱固定件"行(已定约束:泵 TPU 软固定、
  阀阵列梁、罐抱箍、7 路传感器位+感测三通、PCB 柱、理线梳、整舱可拆、
  大质量件贴机身平面摊平、每腿服务环)
- 官方 `component-layout.jpg` + STL 实测:frame 198×205×16mm,
  top-cover4 占位 100×140mm,腹面另有 battery-bar(电池)与
  servo2040-bottom-cover(Servo2040 托盘)

---

## 0. 三个先定下来的架构决定

1. **电池和 Servo2040 不进舱,留在官方腹面位。**
   官方件 battery-bar(电池绑腹面)+ servo2040-bottom-cover(Servo2040 托盘)
   在 P3 打印清单里本来就要打。爬墙时腹面朝墙——电池是最重单件(~350g),
   放腹面恰好是全机离墙最近的位置,重心最优;18 根舵机线也天然在腹面汇聚。
   把它们搬上舱只有坏处。舱只需要:给 Pi↔Servo2040 的一根 USB 留下潜通道,
   给电池 XT60 线束留上行通道。
2. **"Servo2040 靠 Pi"立体实现。** Pi 放在舱前部、frame 中央开口正上方,
   Servo2040 在开口正下方的腹面托盘——两者垂直相邻,一根 15~20cm USB-C
   线穿开口直达。既满足"一根 USB 连线短",又不动 18 根舵机线。
3. **舱做上下两层:下层重、上层轻。** 顶面单层摊不开(器件总占地约为
   top-cover 区面积的 3 倍),必须立体化。原则倒过来用:大质量件
   (泵×2、罐)全部贴底层板摊平,上层夹层只放轻件(Pi ~50g、分压板、
   5V 降压)——夹层抬高 ~35mm 对重心的代价被"上面只有 150g"压到最小。

固定策略类型:**A** M3/M2.5 螺柱直锁(板上有孔)/ **B** 打印卡扣托盘(无孔板)/

底板目标外形 **~190×130mm**(中央区域复用 top-cover4 的 100×140 接口边界,
左右外扩翼压在 frame 顶面实心区上,避开 6 个 coxa 舵机区——净空待实测 §4-14)。

### 2.2 逐条核对布局原则

| 原则 | 落实 |
|---|---|
| 大质量件贴机身平面摊平 | 电池(最重)在腹面=离墙最近;泵×2、罐横放贴下层板;上层只有 Pi+分压板+降压 ~150g。粗算:泵罐阀 ~500g 质心距墙 ~70mm,若再堆一层会到 ~110mm——摊平省约三成倾覆力矩 |
| XL6009 出 12V 紧邻 MOSFET 功率端 | 前半区并排,端子对端子,电源线 <50mm |
| MOSFET 输出端朝阀阵列 | 板输出侧朝后,正对中部阀轨,6 根阀线 <80mm;2 根泵线沿右缘理线梳到尾部 |
| 分压板紧邻 7 路传感器接入 | 分压板在夹层后缘,**正下方就是传感器排座**,7 路线垂直上行 <60mm;到 Pi 走 2×20 IDC 排线(P3 已定,禁杜邦) |
| Servo2040 靠 Pi(一根 USB) | 垂直相邻(§0-2),USB-C 线穿 frame 中央开口 |
| 5V 降压 USB-C 出口对 Pi 口 | 降压模块在 Pi 电源口同侧,出口对准,用 15cm 短线 |
| 气路一条龙 | 尾→前一直线:泵×2 →单向阀×2 →罐→罐口三通(罐压传感器=排座第 7 槽)→歧管→6 阀;全链在后半+中部连续,无跨区长管 |
| 6 阀出口朝六腿分散 | 阀轨横贯中部、正对 ML/MR 腿根;3 路出管向左、3 路向右,沿底板边缘扎带槽走到各腿根,**每腿过 coxa 留服务环**(松弛圈),舱缘扎带槽是最后锚点 |
| 泵震动隔离 | 自带 L 支架 + 3mm TPU 片 + TPU 垫圈,半浮动锁法(§3-3) |
| 电池可拆 | 腹面魔术贴/扎带,充电即取,不动舱 |
| 模块化 | 整舱一块底板,4~6 颗 M3 下机;夹层 4 颗 M3 柱,单独可拆;拆舱不断气路(6 条腿管在腿根侧留快拆点=扎带剪点) |

### 2.3 高度与接口

- 下层板 3mm + 器件:最高是罐(Φ≤70)与泵(~50 含支架),舱高 ~70mm。
- 夹层柱高 ~35mm(下方 MOSFET/继电器净空 ~25 + 排线弯位),Pi 顶面距底板
  ~65mm——与罐同高,不突出。
- 与 frame 接口:优先**复用 top-cover4 的固定形式**(卡口/螺丝,形式待
  实测 §4-14;可从 top-cover4.stl 直接提取轮廓),再加 4×M3 直锁点兜底。
- 开口:底板中央开 USB/传感器线/舵机线下潜口(顺带减重);泵排气口朝尾外,
  阀排气口一侧留豁口不憋在舱内。
- 走线纪律(P3 遗留):12V 功率线与 0.25~2.25V 模拟传感器线**分梳走线**,
  不同理线梳、不并捆;全舱禁面包板/杜邦,JST-XH 或焊线。

### 2.4 重量预算——先泼冷水

2.5kg 总预算 − P3 无吸附参考线 1.9kg = **吸附系统隐含预算仅 0.6kg**。粗估:

| 项 | 估重 g |
|---|---|
| 泵 ×2 | ~260 |
| 罐 | 60~100 |
| 阀 ×6 | 120~200 |
| 歧管+管路+接头+单向阀 | ~120 |
| 传感器 ×7 | ~40 |
| MOSFET + XL6009×2 + 分压板 | ~140 |
| 舱打印件 + 螺柱螺丝 | 200~250 |
| **合计** | **~940~1110** |

**超支 ~350~500g。**对策(按优先级):① 首飞只装单泵,双泵位留着、备泵
在架子上(−130g);② 罐选小号 250mL;③ 打印件以减重为一级目标——3mm 板
+镂空+筋,目标 ≤180g;④ 每件到货即称重记 `weight-log.md`,超 2.2kg
(无吸附)或预估整机超 2.7kg 时启动减重专项。**2.5kg 大概率守不住,
真实落点估计 2.6~2.8kg——这直接吃吸附裕量,P4 验收前要重算吸盘数值账。**

bay_baseplate(p)    # 底板:板体+筋+全部一体凸台+扎带槽+中央开口+frame接口

### 5.2 PARAMS 组织

不动现有扁平 PARAMS(吸盘足/台架件继续用);新增独立的 `BAY` 字典,
**每器件一个子 dict,孔距/外形全参数化**;另设 `BAY_LAYOUT` 位置表,
布局调整只改一张表:

```python
BAY = dict(
    plate=dict(l=190.0, w=130.0, t=3.0, rib_h=6.0, boss_h=6.0),
    pi=dict(hx=58.0, hy=49.0, hole_d=2.3, size=(85, 56)),      # M2.5 自攻
    mos=dict(hx=None, hy=None, hole_d=2.8, size=(None, None)), # §4-3
    relay=dict(hx=None, hy=None, hole_d=2.8, size=(70, 30)),   # §4-12 估
    divider=dict(hx=None, hy=None, hole_d=2.8),                # §4-6
    pump=dict(bkt_cc=None, bkt_hole=None, body_d=None,
              body_l=None, pad_t=3.0),                          # §4-7
    valve=dict(n=6, body=(None, None, None), pitch=None),       # §4-8
    sensor=dict(n=7, body=(None, None, None)),                  # §4-9
    manifold=dict(od=None, port_pitch=None),                    # §4-10
    tank=dict(od=None, length=None, ear_cc=None),               # §4-11
    tray=dict(buck=(None, None, None), xl=(None, None, None)),  # §4-4/5
)
BAY_LAYOUT = {  # 器件名: (x, y, rot°),原点=底板中心,+y 朝头
    "pi": (0, 40, 0), "mos": (25, 18, 0), ...
}
```

**守则:`None` = 待实测。生成函数入口 `assert` 所有用到的 `None` 已回填,
没量完就想出 STL 直接报错**——这就是"用户填实测值即出 STL"的机制。
