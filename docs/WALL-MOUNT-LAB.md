## 0. 通用约定

**供电**：走充电宝那条路。启动死机线未结案，口径是"补足充电宝真实脚本 5 次之前，
别在 XL4015 上跑真实脚本"。脚本启动会打印 Pi 欠压粘滞位，有 ⚠ 先别跑。

**安全**：安全绳绷紧，人在旁边。有足在墙上时 `ESC`×2 会放气 = 坠落，先扶稳；
取机用 `o`×2。

**高度量法**：钢尺立在地面玻璃上，量**机身前缘中点下沿**。手不要扶机身——一扶受力
就变了。同一次实验里始终量同一个点。

**中腿压不压得住（纸条法）**：一条纸条塞到中腿吸盘下面，能轻松抽出来 = 它没压住。
每个俯仰档位查一次。

**状态行速查**：每条腿两个字符 = 相位 + 吸附态。
`·`=站立 `Z`=零力交接 `z`=接管 `V`=放气 `L`=抬起 `T`=平移 `H`=悬停 `D`=下探
`P`=压入 `W`=等吸附 `^`=收在空中；`A`=已吸附 `r`=未吸 `v`=放气中 `s`=抽气中
`!`=漏气。`盘差` = **所有已吸附的盘里最弱的那一只**（"差"是最差的差），
正常 −60~−75，浅于 −50 过不了抬腿门槛，浅于 −20 触发漏气监护。
中腿是 `--support-legs`，常态就是 `·r`（不吸），**不会**出现在 `盘差` 里。

**电流**：`泵开` 时比 `泵停` 时高零点几安，记电流必须同时记泵的状态，否则不可比。

**日志**：`software/logs/mount_*.log`，每拍有逐腿相位/盘压/交接偏移/电流。
跑完 scp 到开发机（`64.176.60.202`）——**A 组那次没留，别再丢了**。

**通用中止条件**（任一出现就停）：
- 被抬的那条腿在 `Z` 段变 `!`，或 `盘差` 快速往 −30 爬 → δ 把盘拔起来了
- 屏幕出现 ⚠ 开头的行（交接截断/接管塞不下）→ 抄下来
- 冻结 → 先看清原因再按 `f`（注意 `f` 会**续铺**在途的交接，不会取消）
- 接管后电流不回落 → 在堵转顶玻璃，退回去
- 机身肉眼可见往墙上贴或歪 → 空格 / `o`×2

## 2. E4：台架两项（不上电，约 15 分钟）——**下一个**

两项都不用上电、不用上墙，但都卡着后面的路。

### E4a 吸盘斜着压还能不能压住

**为什么**：中腿是"只压不吸"，盘面对不对正跟它无关，几何上能撑到 90°（OPEN §1.1）。
但盘面斜到一定角度，接触就会从盘面滚到盘缘、甚至变成盘座/胫骨末端碰地——**那个角度
算不出来，只能量**。量出来的值就是引擎该给 `--support-legs` 放宽到的上限。

**怎么做**：手动把一条中腿摆成吸盘轴与地面法线成 10° / 20° / 30° / 35°，每个角度
压在玻璃板上，看接触的是不是还是盘面（用纸条法或手电从侧面照）。

**记**：

| 倾角 | 10° | 20° | 30° | 35° |
|---|---|---|---|---|
| 接触部位（盘面/盘缘/盘座碰地） | | | | |
| 还压得住吗（纸条抽不出来） | | | | |

**判据**：能压住的最大角度记作 θ_press。按 coxa 只验过 ±55° 的保守口径，中腿在
俯仰 90° 时盘面最多斜 **35°**（OPEN §1.1 表）——θ_press ≥ 35° 就是"中腿可以一直压
到底"，小于 35° 就按它反推中腿能撑到的俯仰。

### E4b 查 L1 那 16 mm 到底差在哪

**为什么**：`--wall-trim L1:16` 现在**自己就吃掉 5° 抬头余量**（仿真：dist 140 下
trim 16 时天花板 10°，trim 0 时 15°），而扶梯入口要 15°。这条从落点精度问题升格成了
**扶梯段的前置条件**。

**新线索**：R1 实测是 **−8**（反方向），两腿差 24 mm。按 OPEN §7 自己立的判据
"两腿一致 = 模型连杆要改，只 L1 偏 = 该腿标定"——**这是 L1 单腿的标定/装配问题，
不是模型的**。

**怎么做**：把 L1、R1 摆到**同一个**命令姿态（前伸上举，就是上墙悬停那个姿势），
量两条腿足端的实际位置差；然后对着 L1 逐项查：舵盘有没有松/装错齿、三个关节的实际角
与命令角差多少（量角器）、软管或线束有没有拉着腿。

**记**：L1 实际比命令短 ____ mm，R1 ____ mm；查到的原因 ____________。

## 3. E5：调参重跑 + 逐级抬头（实机）——**下一个**

一次跑完回答四件事：①两个余量问题解没解开 ②抬头能到几度 ③**中腿在那个俯仰下还压不
压得住地面**（静力那条悬案的第一手数据）④收中腿前后的对照。

### 参数

```bash
python scripts/mount_wall.py --no-tank --wall-dist 140 --press-delta 13 \
    --floor-clear 45 --support-legs L2,R2 \
    --wall-trim L1:16,R1:-8 \
    --handover L1:10,R1:10,L3:8,R3:8 --takeover L1:10,R1:10
```

与 E3 的差别，逐条都有理由：

| 改动 | 为什么 |
|---|---|
| `--wall-dist` 155 → **140** | 站近换抬头余量（每近 15 mm 换回 5°，OPEN §6.1） |
| `--press-delta` 18 → **13** | 地面腿压深余量 10 → 15 mm；不改的话收中腿时 `L3 压入 28 超上限` 当场被拒 |
| 中腿 δ 5 → **0**（不写进 `--handover` 即为 0） | 中腿没真空、没有密封破裂，交接对它们没有"消灭放气弹跳"的作用；而收起后这笔账**还不回来**，纯亏 |
| `--wall-trim R1` 0 → **−8** | E3 现场实测值 |

⚠ **`--press-delta 13` 是这次唯一有风险的改动**：压入行程小了，密封可能变差。
盯启动六足吸附是不是还一次过、`盘差` 能不能压到 −70 以下。吸不上就退回 15 或 18
（退回去的话，收中腿那步会被拒，那就不收中腿、只做到第 3 步为止）。

⚠ trim 是在 155 量的，140 处不一定一样。悬停时目测，不对就用 `.`/`,` 现场调，**记下来**。

### 步骤

1. 就位暂停：量前髋到玻璃的距离，按 `d` 输实测值，`p` 启动
2. 六足吸住 → 量 **H0**；`盘差` 记一次（验证 press 13 的密封）
3. `2` `t` → 等悬停 → `i` → 等收口；`5` `t` `i` → 量 **H1**
4. `1` `w` → 悬停时目测离墙间距，不对用 `.`/`,` 调（**记下最终 trim**）→ `i` → 量 **H2**
5. `4` `w` → 悬停 → 目测与 L1 齐平，不齐用 `+`/`-` → 量 **H3** → `i` → 量 **H4**
6. `3` `b` `i`、`6` `b` `i`（后足指正后）→ 量一次高度
7. **逐级抬头**：`↑` 一次（5°）→ 等"位姿铺完" → 每一档记一行（见下表）→ 再 `↑`。
   直到被拒（预期在 10~15° 被 `L1 吸盘倾角超 15°` 拒）
8. **收中腿**：`2` `h`、`5` `h` → 量高度、记电流 → 再试 `↑` 看还能不能多抬
9. `o`×2 取机 / `ESC`×2 退出；日志传过来

### 判据

- **②抬头**：到不了 10° → 回头查 trim（E4b）；到 15° → 扶梯入口够了。
- **③中腿**（本次最有价值的一条）：到被拒的那个俯仰为止中腿纸条都抽不动 →
  "中腿只压不吸能一直撑着"成立，**四足阶段连同那个 20~23 N 单墙盘剪切有望推迟甚至
  大部分避免**（OPEN §1.1）。中途就抽得动了 → 记下是哪个角度，OPEN §7 那条"中腿只能
  承压不能承拉"就被证实了，扶梯的载荷账要按四足重算。
- **④收中腿前后**：电流跳一截、高度掉一截 = 中腿之前确实在扛事。
