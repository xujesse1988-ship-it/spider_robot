# 唤醒词 / 急停词原始词表 → scripts/voice_setup.sh 用它生成 KWS 的 keywords_hexapod.txt
# 格式：词 @类别 [#阈值] [:提升分]   （'#' 开头整行是注释）
#   WAKE = 唤醒词：听到后进入听令状态（follow_up_s 内可连说多条指令）
#   STOP = 急停词：不用唤醒随时生效，命中即停
# 阈值越大越难触发（默认 0.25）；提升分帮关键词在噪声/回声里活过解码。
# 急停词故意比唤醒更灵敏（#0.20 :2.0）：误触方向是"多停"，安全；且要能在
# 机器人自己说话的回声里捞出用户的喊声（09-02 实机 0.35 时说话期间喊不停）。
# 唤醒词 09-03 也放灵敏（0.25→#0.20 :1.5）：实机反馈走路时（18 舵机噪声糊住
# 麦克风）要喊很大声才唤得醒；误触代价只是偶尔多应一声"在"+开 8s 听令窗，
# 指令还有声纹锁把门，比"喊不应"便宜得多。提升分压着急停的 2.0 一档，
# 别加到平级——急停在任何混叠里都要先活下来。
# 唤醒词建议 3~4 个音节；单字"停"别放这里（单音节误触太多），
# 单字"停"走唤醒后的整句识别照样能停。
# 改完重跑：python -m hexapod.voice.keywords --tokens <kws目录>/tokens.txt \
#            --out <kws目录>/keywords_hexapod.txt --raw hexapod/voice/keywords_raw.txt
小蜘蛛 @WAKE #0.20 :1.5
蜘蛛同学 @WAKE #0.20 :1.5
停下 @STOP #0.20 :2.0
停止 @STOP #0.20 :2.0
停下来 @STOP #0.20 :2.0
别动 @STOP #0.20 :2.0
