# 动画第9、10步：中足上墙几何复核

日期：2026-09-08。对象：`html/ground-to-wall-gait.html`中的第9步L2上墙、第10步R2上墙。仅离线计算，没有打开硬件，也没有新增实机动作。

页面第8～10步现已按本文候选更新为水平前移30 mm、中足在190 mm高度接触墙面；下文“动画原姿态”保留更新前方案作为计算对照。第11步起仍为尚未按新候选复核的概念动作。

## 结论

**动画原姿态不能按当前模型门槛执行；附近存在通过采样几何检查的替代候选。** 中足在原落点并非伸不到，主要问题是吸盘朝向，以及此前机身变化对前足吸盘朝向的影响。不能由此判定机构无法完成中足转墙，也不能把候选几何通过等同于实机能够承重完成转移。

## 动画原姿态

动画第8步将机身原点由 `(0,0,90)` mm变到 `(50,0,100)` mm，并抬头25°，六个接触点保持原位置。墙面位于世界X=243.5 mm；第9/10步中足目标分别为 `(243.5,+95,200)`、`(243.5,-95,200)` mm。

使用43/81/123.7 mm连杆、当前逐舵机标定、项目现有IK分支、自由态吸盘轴偏角−25.2°。舵机原始脉宽不截断，要求距各自电气上下限至少50 µs；接触墙面时轴向偏差≤15°；关节中心到地面/墙面至少10 mm。地面足未吸附，不套用墙面轴向判据。

| 检查项 | 第9步L2 | 第10步R2 |
|---|---:|---:|
| 最终落点IK | 有解 | 有解 |
| coxa/femur/膝弯曲指令角 | −86.45° / 42.17° / 63.77° | +86.45° / 42.17° / 63.77° |
| 原始脉宽（coxa/femur/tibia） | 2391.3 / 1556.7 / 1802.4 µs | 625.7 / 1384.9 / 1083.9 µs |
| 最终墙面吸盘轴向偏差 | **21.98°，不通过** | **21.98°，不通过** |
| 单独检查移动腿的动画路径 | 481个采样点，接触墙面的最后一点不通过 | 同左 |

更早的限制出现在第8步：沿动画所画的机身平移/抬头路线，约在机身前移28.4 mm、原点高95.68 mm、抬头14.2°时，两前足轴向偏差首次超过15°；最终25°姿态时达23.78°。这是该特定组合路线的结果，**不是“所有姿态都最多只能抬14.2°”**。若把前足当前2 mm压入指令计入，首次越界约在13.8°，最终偏差约24.37°。

因此，即使只修改中足最终落点，第8步的前足接触问题仍然存在。动画使用的是动作顺序示意骨架，没有求解这些关节约束，不能照动画角度和坐标直接下发。

## 一组更合适的离线候选

附近有限网格搜索找到了多组端点候选。以下选取的是兼顾较小机身调整、吸盘角度与脉宽余量的一个样本，不是全局最优：

| 项目 | 候选值 |
|---|---|
| 机身姿态 | 保持水平，原点高90 mm |
| 机身调整 | 向墙平移30 mm，六足世界坐标目标暂时固定 |
| 前足 | 仍保持原墙面落点及2 mm压入指令 |
| L2墙面唇心目标 | `(243.5,+110,190)` mm |
| R2墙面唇心目标 | `(243.5,−110,190)` mm |
| 中足2 mm压入后指令 | X=245.5 mm，Y/Z不变 |
| 中足接触墙面时轴向偏差 | 9.50° |
| 中足压入2 mm时轴向偏差 | 8.60° |
| 前足在该姿态的轴向偏差 | 1.65° |

候选路径：机身先前移30 mm；L2在原地面落脚点正上方升到190 mm，再移到墙前60 mm的准备点，然后触墙及压入2 mm；L2固定后，R2按镜像路径转移。返回检查采用R2先释放退离墙面、回原落脚点，随后L2返回，最后反向恢复机身位置。

机身前移以≤1 mm间隔采样，中足转移、压紧和返回以≤0.25 mm间隔采样；每个采样点同时复核其他支撑足。L2/R2转移各1851个点、返回各1850个点，均通过上述IK、脉宽、墙面轴向与关节中心到地/墙的检查。左侧转移全姿态的最小电气余量约104.30 µs、右侧约149.01 µs，均高于50 µs预留要求。IK→FK回算误差小于10⁻⁶ mm。

仍未覆盖：腿间/机身/舵机壳实体碰撞、吸盘边缘和气管包络、地面摩擦与滑移、各足法向/剪切力、舵机带载能力、吸盘剥离力矩，以及抬脚时的实际机身下沉。采样通过也不等同于连续路径形式化证明。**当前实机脚本没有机身前移或中足上墙命令；该候选不能直接在现有交互中执行。**
