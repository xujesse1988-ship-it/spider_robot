腿坐标系到底长什么样

这套坐标系有三处容易卡住，逐个说。

  1. 它是"每条腿一套"，不是全机一套。六条腿各有各的原点、各有各的 +X。 腿的 +X 指的是那条腿的中性朝向（R3 是机体系 −125°），跟机体的 +X（正前）完全是两回事。
  2. 原点不在任何一个看得见的零件上。先找 coxa 偏航轴——就是 coxa 舵盘中心那条竖直轴线； 再沿它往上走 16.2mm，到 femur 舵机轴心那个高度。这一点就是原点 H。这么定是为了让 l1 是纯水平的 43mm（H→F 不带上下分量），运动学公式最省事。
  3. +Y 不用死记。记住 +X 和 +Z 就够了，+Y = Z×X 只是把它补成右手系。 对右腿它指向机体前外侧；在 §2 那张侧视图里它指向纸面里（因为视点在 −Y）。
自测题：coxa 转了 γ，femur / tibia 不动，F 在腿坐标系里的 X 变不变？
变。腿坐标系是钉在机体上的，不跟着 γ 转。γ 一动，整条腿（F、K、足端）都在这套坐标里 绕 Z 轴划圆：F = (l1·cosγ, l1·sinγ, 0)——γ=30° 时 F 的 X 从 43.00 缩到 37.24， 同时多出 21.50 的 Y 分量。

但是：它们到 Z 轴的水平距离 r 和高度 z 一点没变。 rF=l1、rK=l1+l2·cosα、 zK=l2·sinα……只跟 α、θ 有关，与 γ 无关。 所以 §2 那张侧视图跟 γ 完全无关——那也是它没有 γ 滑块的原因。 一句话：γ 转的是"腿平面"这个平面本身，平面里的形状一动不动。

推论：γ=0 时 Y 恒为 0——Y = r·sinγ 对 F、K、C 全都成立， 所以整条腿正好落在腿坐标系的 Y=0 平面上，此时 r = X，§2 那张图的横轴才真的是 X。 γ≠0 时腿仍然是平面的，只是那个平面绕 Z 轴转了 γ，每个点带上 r·sinγ 的 Y。

⚠ 这是模型。实物零件并不对称于这个平面——舵机壳体、叉口都往一侧伸出几十 mm， §2 侧视图是投影不是剖面。至于足端到底在不在这个平面里，那是 docs/L3-DISPUTE-OPEN.md 待办 e「coxa 侧偏检验」（coxa 不动、两个伸展度投唇口两点连线， 量 hip 投点到该线的垂距），至今没做。真有侧偏的话，模型会把它当成一点 γ 零位偏差吸收掉。

角腿的中性朝向不是"从机体中心径向往外"。L1 髋位 (83.5, 63) 相对机体中心的极角是 37.0°，而它的中性朝向是 55°——腿比径向再往外撇 18°。中腿没有这个差（都是 90°）。 相邻腿的中性朝向彼此差 35°（55→90→125），左右对称腿（L1–R1）差 110°。

后果（foot_reach=130 的默认站姿，实算）：L1 足端落在 (158.1, 169.5)， 比"径向放"的 (187.3, 141.3) 偏后 29mm、偏外 28mm，两点相距 40.6mm。整个足迹 前对横跨 339（径向 283）、前后跨度 316（径向 375）——更宽但更短， 支撑多边形面积反而小 9%（1204 vs 1322 cm²）。六个足端也不在同一个圆上： 角腿距机体中心 231.8、中腿 211.5，差 20mm。所以"站位半径"这个说法对本机不成立， 爬墙站位得按每条腿单独算。
⚠ mount_angle_deg 是本包的定义，不是机械事实。 真正的机械朝向由舵盘装在花键哪一格决定，差值被 coxa 的 attach_deg 吸收—— 所以它不影响足端落点的准确性，影响的是默认站姿的形状和 γ 行程的居中程度。 实测（舵机回中时腿的真实朝向 = mount_angle + attach_deg）：L1 50.7°、R1 −54.6°、L2 91.5°、 R2 −90.2° 都在标称 ±4° 内，但 L3 是 139.4°（标称 125）、R3 是 −145.4°（标称 −125）—— 两条后腿实际各往后偏 14.4° 与 20.4°，反而更贴近径向的 ±143°。后果是后腿的 coxa 行程没有居中 （一侧少 14~20°），做大摆幅动作前值得先查这两条腿的余量。

§7用之前要知道的四件事

  1. 81 还是 80。零件的设计值是 80.000（STL 孔位无歧义），config 的 81.0 是实测舵盘螺丝心距—— 多出来的 1mm 是打印公差 + 舵盘/花键间隙的真实堆叠。运动学用 81 是对的（它要的是实际轴距）， 但拿 STL 做干涉检查时别混用。
  2. z = 2.75 这一项还有 ±1 的不确定度。它决定的是"髋点 H 相对 coxa 舵盘面的高度"（16.2mm）。 若要收口：量一下 coxa 舵盘座面到 femur 舵机轴心的竖直距离即可，预测 16.2±1。 它不影响 l1/l2/l3 和任何运动学数字——腿坐标系的 z=0 平面本来就定义在 femur 轴上。
  3. 吸盘是两态的。本图画的是自由态（h_cup=19、l3=123.7）。吸住以后波纹压实， h_cup ≈ 7.5~8、等效 l3 ≈ 113.8、δ 也变成 27.6°。P4 的记账口径是"全程自由态模型 + press_delta"， 不要把两套口径混着用（P4-GUIDE §4.2）。
  4. config 的髋距还没跟实测对齐。L1–R1 实测 125（config 126）、L1–L3 实测 165（config 167）， frame.stl 反推 125.27 / 165.53 与实测咬合——官方那三个整数是取整过的设计意图，偏大 1~2mm。 改 config 要三条一起改（L2–R2 还没量，预计 ≈162.5），所以现在 mount_x/mount_y 保持 83.5 / 63.0 / 81.5 不动。影响面：每个髋位偏 0.5~1mm，地面步态无感；爬墙站位按 mm 算裕度， 但远小于腿链弹性让位（13~27mm），不急。
