# 地-墙过渡 · 摩擦上墙前期（泵不开，抬到 60~70°）

> 2026-09-13 开。**用户提出的新路线**：吸盘吸得太死，关节舵机就动不了，所以抬头前期**不抽气**，
> 靠吸盘和玻璃的摩擦撑住、地面腿用力顶。脚被动吸住一点没关系，**但抬腿前必须开电磁阀放气**。
> 抬到 70° 左右再开始抽气（负压 −40~−60 kPa 就够），过 80° 再加到 −70。
> **本文只做前期**：泵不开，看能抬到多少度，**到 60° 就算过**。
> 分支 `wall-mount-transition`，跑之前先 `git pull`（09-13 改了引擎：只承重腿抬腿前也先开阀放气 0.3 s）。
> 几何与原因分析以 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md) 为准，吸附路线的实验记录在
> [WALL-MOUNT-LAB.md](WALL-MOUNT-LAB.md)。

## 0. 干跑结论（先看）

1. **吸住的脚确实把抬头卡死了。** 引擎给吸附腿的倾角容差是 15°（吸盘密封的容差），E5b/E6 就卡在
   指令 14~16°；只承重腿（`--support-legs`，不抽气）的容差是 35°（E4a 台架实测）。六条腿都设成
   只承重，干跑能抬到**指令 64°，多做一步到 70°**。
2. **泵不开，站得住主要靠摩擦**（脚只能推、不能拉）。按整机 3.54 kg 逐步算静力平衡，**只算摩擦**时
   各段需要的最小摩擦系数：

   | 步骤 | 接触 | 只靠摩擦需要的系数 |
   |---|---|---|
   | 1~11（0°→36°，中腿还在地上） | 6 个脚 | 0（第 8 步抬中腿那一下 0.51） |
   | 12~14（收中腿，36°→64°） | 前 2 墙 + 后 2 地 | **0.57** |
   | 15（再挪一次后足到 70°，抬后足时只剩 3 个脚） | 3 个脚 | **0.73** |

3. **这些数偏保守。** 气管接着、站立时阀不通电，脚一受压就会被单向阀憋出被动负压
   （P4-GUIDE 实测最多 −40~−60 kPa，约 30~40 N），只会帮忙；但有多少、会不会漏掉说不准，没算进去。
   纯摩擦能参考的是 [CLIMBING-DESIGN.md](CLIMBING-DESIGN.md) §2 的吸附实测（剪切 15 N ÷ 法向 25 N = 0.6）：
   光靠摩擦 64° 压线、70° 大概率滑。**最可能打滑的仍是第 12~14 步**。
4. **换前足必须在中腿还压在地上时做。** 干跑对比过：34° 先收中腿再换前足，抬前足那一下只剩
   3 个脚，只靠摩擦要系数 1.9，必翻。所以第 10 步排在第 12 步前面。
5. **实测角度会比屏幕上的指令低。** 吸附路线量过：真实 ≈ 0.89×指令 − 3°（只验证到 16°）。
   照这个算，指令 64° 只有真实 ~54°，**所以"到 60°"以照片量出来的为准**。

## 1. 准备

1. 气管照常接着，不用动。
2. 地面和墙面玻璃擦干净、擦干（摩擦对灰和水很敏感）。
3. 安全绳绷紧；人站在侧面，手随时能托住机身。
4. 白板笔：每只脚放好后，沿吸盘边在玻璃上画一道短线（地面脚画后边，墙面脚画下边），
   滑没滑就看它。
5. 手机固定在机器人**左侧**，和机身同高、正对着。每步做完拍一张：照片里 L1、L3 两个 femur
   舵盘中心的连线与地面的夹角，就是真实俯仰。
6. 站位：前腿 coxa 舵机轴离墙 **135~142 mm**（干跑在这个范围都能到 60°；140 时每次拒绝都和
   下表一字不差）。

## 2. 命令

```bash
python scripts/mount_wall.py --dry --support-legs L1,R1,L2,R2,L3,R3 \
    --wall-dist 140 --pitch-step 2 --pitch-max 70
```

| 参数 | 为什么 |
|---|---|
| `--dry` | 泵不转，吸附状态机是仿真的；**真阀照常动**：站着时断电（被动吸住无妨），抬腿前通电放气 0.3 s，落下压好后断电。屏幕上的盘压、罐压、泵开/停、"吸附完成"都是假的，不用看 |
| `--support-legs` 六条全写 | 引擎把六条腿都当"压到位就算站住"：不抽气，倾角容差 35°。⚠ 这些腿不参与互锁：**没有"其余脚站稳了才许抬腿"这道保护，引擎也不算会不会翻**，全靠人看 |
| `--wall-dist 140` | 就位暂停时量一下，按 `d` 填实测值 |
| 不给 `--wall-height` | `w` 取当前俯仰下可落足带的中点，每次换前足，落点自己往上走 |
| `--pitch-step 2`、`--pitch-max 70` | 每次 2°，最高 70° |
| 不开 `--handover` / `--takeover` | 干跑是按不开算的，先少一个变量 |

## 3. 步骤

全程规则：

- **只按表里的键。** `↑` 被拒什么都不会动，多按无妨；表外的 `]` `←` `→` 不要按（会改变后面的路线）。
- 抬腿时先原地停 0.3 s（开阀放气）再抬，这是正常的。
- 每次按 `i` 后，看吸盘唇边确实压在玻璃上，再画线。**墙面脚没压上**：选中那条腿按 `.`
  （往墙里多压 2 mm），一次加一点。

## 4. 什么时候停（出现任何一条）

- 任何一只脚离开笔线超过 3 mm，或者还在慢慢挪：机身正在动就按 `空格`（停在半路），手托住，
  记下"第几步、哪只脚、往哪滑、滑了几毫米"。
- 抬一条腿时机身往那边歪：托住；那条腿还悬停着就按 `i` 放回去。
- 抬腿时吸盘粘着不离开玻璃（阀没开？）：托住，`o`×2 冻结，查那一路阀。
- 电流持续超过 4 A 不回落（吸附路线实测最高 3.5 A）：腿在硬顶，记下来，按 `↓` 退一档。
- 冻结，或屏幕出现 ⚠ 开头的行：原样抄下来。

机身后下沿蹭到地面不用停（引擎以为还离着几毫米），记一笔就行。

## 6. 判据（跑之前定死）

| 结果 | 说明 | 下一步 |
|---|---|---|
| 照片量出 ≥ 60°，静置 30 s 不滑 | 前期不抽气这条路成立 | 设计 70° 以后的抽气段。负压要 −40~−60，而现在泵的开停阈值写死在 −60 / −75（`adhesion.py`），要改 |
| 第 8~14 步滑了 | 摩擦加被动负压不够（光算摩擦要 0.51~0.57） | **后足往后滑** → 地面后足改成抽气吸住；**前足沿墙往下滑** → 先试前腿按 `.` 多压 2~4 mm，还滑就把墙面脚抽气提前，不必等到 70° |
| 第 7 步以前就滑了 | 不是重量的问题（这几步算出来不需要摩擦），是前腿顶墙把机器人往后推 | 前腿按 `,` 少压 2 mm 再试 |
| 到 64° 没滑，但照片量出不到 60° | 摩擦够，差在机身弹性下沉 | 做第 15 步（只靠摩擦要 0.73，托好） |

## 7. 干跑是怎么算的

- 真引擎（`MountEngine`）按第 3 节逐键重放，六条腿只承重，表里每句"拒"都是干跑原话。引擎不读
  传感器，站位和按键一样，实机的拒绝点就一样（E5b 实测过，与干跑一字不差）。站位 135~142 mm
  都试过，都能到 60°，个别步骤的按键次数差一两次。
- 静力：每次抬腿、每档俯仰都求一次"有没有一组接触力能让机身不动"（脚只能推，摩擦力不超过
  摩擦系数×压力），二分出最小摩擦系数。重心按整机 3.54 kg、每条腿 0.32 kg 分到髋 / F / 膝 /
  小腿 / 足来估。**只算了摩擦，没算被动负压**（大小说不准），所以偏保守。
- 摩擦系数和干跑能到的指令俯仰：0.5 → 50°（要把机身往墙推十几次，不推荐）；
  **0.6 → 64°（本文的走法）**；0.7~0.8 → 70°。
