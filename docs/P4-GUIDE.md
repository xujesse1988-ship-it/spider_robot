## 第 0 步 · 先想清楚的三件事（影响后面所有工序）

**1. 步态引擎要做结构性改造，不是调参。** P3 的 `gait.py` 是纯开环相位表：
假定地面永远在 z0、触地精确发生在相位边界；触地瞬间垂直速度恰好最大
（默认参数 ≈170mm/s，"拍地"）；一过相位边界立刻横向拖脚。这三条对
"落脚即密封"全是反的。P4 要把它改成**事件驱动**：相位推进能被每条腿的
吸附事件暂停，摆动相收尾变成"减速竖直下探 → 压入 → 等真空确认"。
详见第 4 步。

**2. 吸附账要按实测重量重算。** P4-BAY-DESIGN §2.4 已泼过冷水：吸附系统
隐含预算 0.6kg，粗估 0.94~1.11kg，整机真实落点估计 2.6~2.8kg。单吸盘竖直
玻璃实测：法向拉脱 25N、剪切 15N（CLIMBING-DESIGN §漏项）。五足支撑剪切
承力 75N，对 2.8kg（28N）安全系数 ≈2.7——还活着，但每件到货必须称重记
`weight-log.md`，上墙前用实测整机重量把这笔账重新算一遍写进本文件验收表。

**3. 舵机保护三原则**（P3 舵机讨论的结论，贯穿全部步态设计）：

| 原则 | 落实 |
|---|---|
| 瞬态外力可接受 | 偶发的吸附拽动、没压够重试，不用追求零外力 |
| **稳态对抗必须靠改指令消除** | PWM 舵机没有单路使能/力矩模式/位置回读，唯一手段是让指令跟着物理走（预压行程,第 4.2 节）；判据 = 吸附后总电流回落基线 |
| 绝不超堵转 | 35kg·cm 按 50% 降额（P2 实测口径）；步态宁慢勿快；使能中永远不许手掰 |

墙上与地面的本质区别：支撑足在墙上**持续**承剪切载荷（P2 实测单腿 hold
0.61A），五足支撑就是 ~3A 级持续电流 + 持续发热。这是常态不是异常——
`walk_teleop` 式的电压/电流状态行必须保留并加峰值/单足回落判据。

## 第 2 步 · 电气与 IO：`Pi5VacuumIO` 从 1 足扩到 6 足（2~3 天）

> **2026-08-14 软件侧完成**：下列 1~6 已全部落码进 `adhesion.py`（GPIO 表
> 08-14 点动实测过；7 路传感器映射照 p4_sensor_check；毛刺抑制改为时间窗
> 判据；罐压独立通道 + 出界判失效停泵置 `tank_fault`；仲裁位 `mode` 占位）。
> 待实机复核：整链 50Hz 主环耗时（ADS 已提到 860SPS + 0.05s 读数缓存）。

现在的 `adhesion.py` 是 P1 台架版：`VALVE_PINS = [5]`、单泵、单 ADS1115。P4 扩展：

1. **通道分配**：YYNMOS-8 恰好 8 路 = 6 阀 + 2 泵（首飞泵 2 路并定义、只接 1）。
   GPIO 引脚表定下来写进 `Pi5VacuumIO` 类常量，和 `config.py` 的腿序一一对应。
2. **压力 7 路**：2 块 ADS1115（0x48/0x49）共 8 通道，足压 ×6 + 罐压 ×1。
   足压传感器装**阀与吸盘之间（吸盘侧）**——阀关着也能读脚压，吸附确认和
   打嗝检测都靠它（P1 单传感器教训 + P2 打嗝实测 30s 进失控）。
   PGA 必须 ±4.096V（±2.048 在放气确认区间削顶,见 `adhesion.py` 注释）。
3. **逐路电学验证**（不接气路）：工具 `scripts/p4_sensor_check.py`，只读 I2C
   不碰 GPIO，所以气路和 MOSFET 板没装也能跑。不带参数出自检报告（8 通道
   逐路判定 + 大气点一致性 + 噪声），`--live` 吸气验证读取链路，`--wiggle N`
   抓瞬断（见下条）。阀侧另测：每路阀听得到吸合声、泵能起停。

   **2026-08-11 实测（六路足压，罐压/备用未接）**：大气点极差 12mV ≈ 0.3kPa、
   噪声 1.0mV ≈ 0.05kPa。偏差远小于 -30kPa 判据，**统一用 `V_ATM=4.486` 即可，
   不必逐只标定**（原计划的"7 只写成表"可省；真要标用 `--zero --save`）。

   量程方向以 P1 实测为准：**大气 4.5V、-100kPa 0.5V，分压后大气点 ADC ≈2.243V**。
   `html/p4-divider-board.html` 检验清单里"大气 ≈0.25V"那句写反了，按它核对会
   把好板子当坏的。未接的通道被下臂 10k 拉到地 ≈0V，据此和在线通道区分；
   第 8 路只留焊盘、没装分压，AIN 悬空读数飘属正常。

4. **毛刺抑制（新增，必做）**：状态机现在是单点判据——`adhesion.py` 里
   `read_foot_kpa(i) <= ATTACH_KPA` 一次读数就翻 ATTACHED。**改成连续 N 次
   采样都满足，或取中值滤波**；ATTACHED 漏气报警（压力回升 >10kPa）同样处理。

   理由：足压是判 ATTACHED 的唯一依据，一次假的深负压读数会让状态机误判该足
   已吸牢，于是放行抬起另一条腿，五足支撑变四足。判据必须扛得住单点毛刺。

   **2026-08-11 的一次误诊，流程记下来备用。** 症状：S7 碰一下读数就跳、
   过会儿又不跳；`--wiggle 7` 抓到 100 次"瞬断"。差点去拆焊点，实际结论是
   **人体静电耦合，板子完全没问题**。三步排除法：

   | 步骤 | 观察 | 结论 |
   |---|---|---|
   | `--wiggle` 看方向 | 正负严格交替、幅度对称 | 真瞬断是**单向**的（线断了分压点只被下臂拉向地），交替 = 围绕基线摆动，不是断连 |
   | `--scope` 看幅度 | 最大偏移仅 -2.8kPa | 真开路应冲到 **-112kPa**（满量程）。线要么断要么不断，不会"断一点点" |
   | 拆开「电」与「力」 | 塑料笔杆按压（只给力）无反应；放完静电轻触（只给电）复现 | 静电注入，非机械/压电 |

   决定性的一步是**对照另一路**：`--scope 2` 表现完全相同 → 板级共性，
   与 S7 的焊接无关。**任何单路怀疑，先测第二路做对照**，能省掉大量返工。

   飞行时电池供电、无人触碰，人体静电这条路径不存在，所以此现象对上墙无威胁。
   但它证明了一件真事：**分压节点确实对注入电荷敏感**——源阻抗 10k∥10k=5k，
   100nF 的转折频率 318Hz，只挡高频。飞行时的真正攻击者是**泵/阀开关瞬变和
   舵机电流冲击**，同样在低频段，所以第 3 步装完泵阀后必须复测（见下）。

   工具用法：`--wiggle N` 抓瞬断（会自动识别正负交替并提示改用 `--scope`），
   `--scope N` 出波形图 + 频谱，按"方向 + 幅度"定性——全单向且峰峰 >20kPa
   才是真瞬断，那时才按"传感器本体 → 根部出线 → 线束中段 → S 口接头 →
   敲焊点 → 掰板子"七步定位，修法是重压端子或直焊+热缩，**不是"再插一次"**。
   软件毛刺抑制是第二道防线，不能替代第一道。

5. **罐压通道的坑**：`read_tank_kpa()` 现在直接返回 `read_foot_kpa(0)`。储气罐
   没到货、S1 空着时该通道读 ≈0V，换算成 **-112kPa**，比 `PUMP_OFF_KPA=-65`
   还低 → 泵滞环认为罐内真空充足 → **泵永远不启动**。扩到 7 通道时一并修：
   罐压走独立通道号，并对"读数超出 -100~+10kPa 合理区间"判传感器失效报警。
6. **仲裁位**（远期双墙面混合足预留）：`AdhesionController` 的步态层接口里
   给每足留一个 `mode` 字段占位，本阶段恒为 `suction`，不实现任何逻辑。
7. 舵机总电高边继电器（切正极）**08-15 定案改由 Pi GPIO17（Pin11）驱动**，
   不再走 Servo2040 A0/GPIO26：模块跳线插 **H**（高电平吸合），线圈 DC+
   取 5V/5A 降压输出（与 Pi 同源，~100mA）、DC− 共地，IN1 ← GPIO17。
   `driver.enable()` 串口 RELAY 照发（保固件使能），功率通断由 GPIO17 收口。
   好处：chica 固件死机时 Pi 仍能独立断舵机电；Pi 进程退出/重启 GPIO 回
   输入态 → 继电器自动释放，天然急停兜底。断舵机电不影响 Pi 和气路——这是
   墙上急停的分级基础：先断舵机（常闭阀保真空，机器人挂住不掉），人再接。

### 4.1 摆动相从"一条曲线"改成分段状态机

每条腿的摆动相拆为（配合 `adhesion.py` 每足状态机）：

```
LIFT     通大气的同时抬离：足端目标沿面法向退开 ≥15mm（吸盘回弹行程 11~13mm
         会把脚顶回面上，必须边放气边走）
TRANSFER 平移到落点上方：沿用现有 smoothstep + 正弦抬腿形状
DESCEND  落点正上方竖直减速下探：XY 冻结，接近速度压到慢速（几十 mm/s 级，
         架空实测定值）——消灭现在"触地瞬间垂直速度最大"的拍地
PRESS    压入预压行程 press_delta（见 4.2）：XY 继续冻结，慢速；
         结束即 adhesion.request_attach(i) → PRESSING → SUCKING
WAIT     等 ATTACHED（-30kPa）；相位推进在此暂停，抽不上转 FAULT：
         抬 5mm 回 DESCEND 重试，连续 3 次失败 → 全机停走报警
LOAD     ATTACHED 后：足端目标切到压入后的位置保持（4.2），该腿转支撑相
```

支撑相和释放对称：重心先移走（该腿卸载）→ `request_release` → VENTING →
RELEASED → 才允许 LIFT。

### 4.2 预压行程与两态足端目标（消灭稳态对抗的关键）

§4.4 三态实测（LEG-GEOMETRY-OPEN.md）换算成步态参数：

| 状态 | h_cup | 含义 |
|---|---|---|
| 自由 | 19~21mm **按腿各测** | 摆动相几何，定案 l3=123.7 基于 L1 的 19 |
| 压到密封 | 7.5mm | **press_delta = h_cup_free − 7.5 ≈ 11.5~13.5mm** |
| 真空 -40~-50kPa | 8mm | 与密封态只差 0.5mm——**先压密封再抽气，抽气几乎不再动** |

实现口径：**不改动定案 `tibia_len=123.7`**，在 `config.py` 每腿新增
`press_delta_mm`，步态在触地点沿面法向加这个量作为压入段与吸附保持段的
足端目标。两态 l3 与"目标点加 delta"数学等价，后者不碰已定案的标定链。
（关联件：`workspace_analysis.py` 的 `CUP_DELTA=-25.2` 已按吸附态修订
——L3-DISPUTE 待办 g——落点带用它复核。）

**验收判据（每次实机跑都看）**：ATTACHED 并切换目标后 ~2s 内，总电流应
回落到接近该支撑构型的基线。某腿吸附后总电流持续多挂 ~0.6A = 该腿
press_delta 没吃干净（复测该腿 h_cup），舵机在和真空对抗。

### 4.3 落点与唇口姿态约束

- 唇口倾角容差 **±15°**（P1 台架实测）。3DOF 腿控制不了吸盘朝向——倾角由
  落点位置几何决定，所以这是**落点选择约束**（workspace 层），不是步态能
  逐步补的。平地/竖墙在设计站姿附近天然满足；落点带越界的步长直接拒绝。
- 压入方向沿面法向、XY 冻结是**步态硬规则**（4.1 已定），否则唇口蹭移密封失败。

### 4.4 触地判据

平面位置已知（地面/玻璃墙都是平的），主路线用**开环压入 + 电流监护**：
DESCEND 段按已知平面高度走到位再转 PRESS，全程盯总电流增量做两件事——
撞早预警（还没到预期高度电流就陡增 → 停）和触地确认。总电流分辨率
81mA/LSB，单腿压入增量百 mA 级可辨，阈值靠架空 vs 落地对比标定。
足压传感器是第二判据：PRESS 结束开阀后压力不降 = 唇口根本没贴上。

### 4.5 CLIMB 步态与安全互锁

- 用 `gait.py:29` 预留的 CLIMB（5/6 占空，wave 相位，一次一腿）。三角步态
  两腿组同时吸放，泵和时序都紧张，爬墙不用。
- 互锁（比 `adhesion.py` 注释的 ≥4 更严，首爬用严的）：**抬任一足前，其余
  5 足全部 ATTACHED**；相邻足不同时释放（CLIMBING-DESIGN §漏项约束）。
- ATTACHED 漏气报警（压力回升 >10kPa）：该足立即重抽挽救；挽救 2s 无效 →
  全机冻结当前姿态 + 报警（五足里坏一足还有 4 足,安全系数仍 >2）。
- 泵滞环 -60/-75kPa（2026-08-17 从 -55/-65 加深：带宽 10→15 拉长补抽间隔，
  整体更深加吸附余量）。⚠ -75 顶着 555 泵标称极限下限（-75~-85），且每足
  单向阀装机后盘压下限 = 泵极限 + 阀开启压差——须实测盘压 plateau 过 -75
  才算数，过不了泵永不停机，双线一起回调到 plateau 浅侧 ≥5kPa 处。
  步态周期先放到 3~4s（cycle_time 可调），跑顺再提速。
- 下滑补偿（`climb_sag_comp_mm` / `--sag-comp`，默认 0=关，2026-08-17 上墙
  实测后加）：竖墙实测"每抬一腿整机被拽下一截"——载荷从 6 足重分配到 5 足，
  弹性让位（波纹盘横向变形 + 舵机载荷让位角）被下一次吸附锁死成棘轮，
  6 次/周期能吃掉整个步幅 = 原地踏步。补偿在每次抬腿事件的 LIFT+TRANSFER
  段（摆动足离面、没有盘在压入）把全部支撑足沿身体系"下坡"方向（头朝上
  贴墙 = -X，随积分航向旋转）额外匀速平移设定量，把身体顶回去。每事件
  实际量 = min(设定, (40−半步幅)/5)：支撑尾端总外摆超 40mm 后腿出 IK 包络
  （满速 4mm 封顶，降速走步幅缩小、限额自动放宽）；目标出工作空间时
  climb_walk 有降落伞——冻结悬停，不让异常炸控制环。标定口径：先白板笔在
  支撑盘旁点标记走 3 周期分清损失类型——**标记不动而身体下沉 = 弹性棘轮
  （可补）；标记跟着盘走 = 界面滑移（补不回，查清洁/盘压）**。确认弹性型
  后从 2~3mm 起步逐次加，盯每周期净位移，取实测下沉量八成以内。⚠ 超过
  真实下沉的部分会把吸附中的盘沿面往下坡拖，宁欠勿过。

### 4.6 开发顺序（全部先在 Mock 上）

1. `MockVacuumIO + MockDriver` 联跑新步态状态机，pytest 补用例：正常循环、
   SUCKING 超时重试、ATTACHED 漏气、互锁拒抬；
2. `sim_walk.py` 出 GIF 目检摆动相分段轨迹（竖直下探段看得见）;
3. 实机架空：六腿空走 CLIMB 步态 + 阀/泵真动作（吸盘悬空必然 FAULT，
   正好验证重试和互锁路径）；
4. 地面玻璃板：进第 5 步。

## 第 5 步 · 地面吸附行走——时序总装验收（1 周）

水平玻璃板（垫实、擦净）上跑完整"压-抽-确认-走-放"步态。这一步验证的
是**时序**，风险为零（掉不下去），必须在上墙前把以下全部打勾：

- [ ] 连续 20 步无 FAULT（或 FAULT 全部自动重试成功）
- [ ] 每步吸附后总电流回落基线（4.2 判据），无持续对抗腿
- [ ] 抽气时间/罐压恢复满足步态周期（不满足：放慢周期或上第二泵）
- [ ] 释放侧无"顶脚"现象（LIFT 边放气边退的时序对了）
- [ ] 走停 10 分钟，无舵机烫手（对抗已消、载荷正常的旁证）

## 第 6 步 · 上墙：斜面递进 → 竖直（1~2 周）

姿态原则：身体贴近墙面（重心距墙越近，上排吸盘剥离力矩越小,ROADMAP 已定）。

| 级 | 面 | 通过标准 |
|---|---|---|
| 1 | 30° 斜玻璃 | 上爬 0.5m,无 FAULT 级联 |
| 2 | 60° 斜玻璃 | 上爬 0.5m + 静停 1 分钟 |
| 3 | 竖直,离地 0.3m 起 | 上爬 0.5m |
| 4 | 竖直 | **验收:上爬 1m、横移 0.5m** |
| 5 | 竖直 | **验收:断电悬停 5 分钟**(断舵机电+泵电,常闭阀保真空;人在旁待接) |

每级全程安全绳（顶部打点,登山辅绳留轻微余量,打点先做承重测试）、地面垫子。
横移和上爬用同一步态引擎,只是速度向量不同——CLIMB 步态本身无方向性。

## 常见问题

| 症状 | 处理 |
|---|---|
| 某腿 SUCKING 频繁超时 | 按序查:唇口倾角(落点在工作带边缘?)→ press_delta(该腿 h_cup 实测过没?)→ 该路气管/三通泄漏 → 唇口酒精清洁 |
| 吸附后总电流不回落 | press_delta 没吃干净,舵机对抗真空;复测该腿两态 h_cup(杯批次差 2mm,别用 L1 的值套全部) |
| 打嗝(足压周期性回升又抽回) | P2 老对手:微泄漏。唇口清洁、检查该足吸盘座密封;打嗝超 30s 按失控处理(P2 实测教训) |
| 某路足压偶发跳变/碰线就跳 | **别急着判接触不良**(2026-08-11 差点误诊)。按序：① `--scope N` 看形状,真瞬断是单向台阶且冲到 -112kPa 附近,双向尖峰/几 kPa 都不是;② 对照测另一路,一样跳 = 板级共性不是本路问题;③ 塑料笔杆按压 vs 放静电后轻触,分开「力」和「电」。确属瞬断再用 `--wiggle N` 七步定位,修法是重压端子或直焊+热缩 |
| 泵/阀一动就冻结 IO 持续失败(Errno 121) | ADS1115 被 12V 开关瞬态干失联(08-23 实测:三次 121 全落在泵/阀通电后 0.05~0.6s 内、均 <1s 自愈、IO错计数全场 0=芯片失联前健康;TLM 电压平稳没用——那是舵机母线,看不见 12V/3.3V 瞬态)。软件已有 0.5s 容忍+重试骑过毛刺;复发查硬件:①泵/阀续流二极管 ②ADC 分压板供电去耦(100nF+10µF)与地线拓扑(别与泵电流共走) ③I2C 线离 12V 束、加绞地 ④电池充满(升压板输入越低开关瞬态越凶,7.72V 起跑那次就炸,8.03V 那次没事) |
| 罐压跟不上步频 | 先放慢 cycle_time,再上第二泵;泵一直响不停 = 系统性泄漏,回第 3 步验漏 |
| LIFT 时脚被"粘"在面上拖 | 放气没到位就抬(VENT_TIME/RELEASE_KPA 判据没等到)或该路阀排气堵 |
| 地面 walk_teleop 抬腿幅度极低、吸盘不离地(装气路后才有) | 不是重量:阀断电=通罐位,吸盘经每足单向阀接歧管,身体一压把空气挤进歧管、抬腿时单向阀不让回流→被动真空锁脚(30mm 盘约 -40~-60kPa≈30~40N,超 femur 足端拉力)。walk_teleop 默认 `--vent` 六阀排气(线圈通电≈25W),`--no-vent`/v 键做对照;同类不跑吸附状态机又要抬腿的地面脚本同坑 |
| 墙上原地踏步(每抬一腿整机下滑一截) | 先分清损失在哪:玻璃上支撑盘旁点标记走 3 周期——标记不动而身体下沉=弹性棘轮:08-20 量化 83% 的下滑在放气密封破裂一瞬(慢放气无效),首选 `--handover`(vent 前零力交接,起标=实测单次弹跳×0.8,docs/HANDOVER-DESIGN.md,body_lean 原地 A/B 标定 δ);`--sag-comp` 是坠后追补的治标层(§4.5),与交接 A/B 期只开一个;标记跟着盘位移=界面滑移,酒精清洁玻璃+唇口,盯状态行"盘差"(盘压压不进 -75 泵不停=真空浅,法向力和横向刚度都打折);无罐模式吸附慢、蠕变时间占比高,装罐后会明显好转 |
| 抬脚瞬间整机晃动 | 释放前重心没移够,该腿还承着载;检查支撑多边形计算 |
| 走几步某舵机烫 | 墙上持续载荷是常态,但单腿明显更烫 = 承载不均或残余对抗;对照电流曲线找腿 |
| 墙上 Pi 重启 | 欠压=坠机级事故。立即停,查 5V 独立供电与 `get_throttled`,修好前不上墙 |
| 阀通电反而吸不住 | 常闭阀口接反(进/出/排气三口)或 `VALVE_ON_LEVEL` 电平反 |
| 断电悬停掉压快 | 逐段验漏定位;接头补环氧;唇口清洁;罐容量复核 |

## 安全

- **安全绳全程不摘**,包括斜面级;打点先做人力冲坠测试;绳留轻微余量不影响步态。
- 垫子铺满作业面正下方;首爬高度 0.3m。
- 断电悬停测试人站机器旁,手虚扶不接触。
- 舵机使能中不许手掰任何关节(35kg·cm 打齿);调整姿势先断舵机电——
  常闭阀会保持吸附,机器人不会掉。
- 墙上任何异常(打嗝、FAULT 级联、异响、烫)先冻结姿态观察,不要急着继续走;
  吸附态冻结是安全态,乱动才危险。
- 锂电规矩同 P0~P3:充电不离人、XT60 随手可拔、先断电再改线。
