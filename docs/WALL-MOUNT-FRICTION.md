# 地-墙过渡 · 摩擦上墙前期（泵不开，抬到 60°）

> 2026-09-13 开，同日第二版。**用户提出的新路线**：吸盘吸得太死，关节舵机就动不了，所以抬头前期**不抽气**，
> 靠吸盘和玻璃的摩擦撑住、地面腿用力顶。脚被动吸住一点没关系，**但抬腿前必须开电磁阀放气**。
> 抬到 70° 左右再开始抽气（负压 −40~−60 kPa 就够），过 80° 再加到 −70。
> **本文只做前期**：泵不开，看能抬到多少度，**到 60° 就算过**。
> **第一版（16 步）作废**：实机第 5 步后腿 femur 基本着地，原因见 §0 第 2 条。
> 分支 `wall-mount-transition`，跑之前先 `git pull`（09-13 改了引擎：只承重腿抬腿前先开阀 0.3 s、
> 新增 femur 离地检查、`t` 键可收近）。几何与原因分析以 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md) 为准，
> 吸附路线的实验记录在 [WALL-MOUNT-LAB.md](WALL-MOUNT-LAB.md)。

## 0. 干跑结论（先看）

1. **吸住的脚确实把抬头卡死了。** 吸附腿的倾角容差是 15°（吸盘密封的容差），E5b/E6 卡在指令 14~16°；
   只承重腿（`--support-legs`，不抽气）的容差是 35°（E4a 台架实测）。
2. **第一版为什么撞地**：引擎只查膝离地，不查 femur。后腿指正后时 F 点（femur 舵机轴）在髋后面 43 mm，
   抬头时它最先往下走；E6 实测后腿 F 每度比模型多沉约 0.7 mm，第 5 步（指令 22°）实物 F 只剩约 27 mm，
   femur 杆就贴地了。现在引擎要求 femur 段离地 ≥ 42 mm + 0.7 mm×俯仰°，**机身必须边抬头边升高**：
   18° 升到 95、28° 125、42° 150、56° 190（模型高度 mm）。
3. **中腿这版不收近。** 收近确实省力（指令 22° 时从 177 收到 140，femur 扭矩少三成），但机身还低时收近会让
   吸盘更斜：中腿倾角 = 抬头带歪腿平面的那部分 + 收近带来的腿平面内倾斜。干跑（要求中腿撑到 34° 再收）：
   收到 140 在 26° 超 35°、整条卡在 28°；收到 160 卡在 32°；**不收近能撑到 34°、整条到 60°**。
   机身升高后收近才等于对正，但那时中腿已快够不着地。`--fwd-reach` 已加，想对照可以用。
4. **只靠摩擦要的系数比第一版低**：机身更高、后腿换回站位方向后，4 个脚阶段只要 0.31~0.38；最紧的是
   第 8 步抬中腿那一下 0.51（CLIMBING-DESIGN §2 吸附实测剪切/法向 = 0.6）。被动负压没算进去，偏保守。
5. **舵机扭矩**：按最省力的受力分配算，全程最大关节扭矩不超过 11 kg·cm（DS3235 额定 35），最吃力的是
   后腿 coxa。实际分配只会更差，但有三倍余量。
6. **换前足必须有足够的脚撑着**：第一版干跑里中腿先收、再换前足，要摩擦系数 1.9，必翻。本版第 12 步换前足
   时中腿还在地上；第 16、20 步是 4 个脚时换，只要 0.38（机身高了、后腿收到了站位方向）。
7. **实测角度会比屏幕低**：吸附路线量过 真实 ≈ 0.89×指令 − 3°（只验证到 16°），照这个算指令 56° ≈ 真实
   47°、60° ≈ 50°。**"到 60°"以照片为准**，照这个关系大概率到不了真实 60°，先看能到多少。

## 1. 准备

1. 气管照常接着，不用动。
2. 地面和墙面玻璃擦干净、擦干（摩擦对灰和水很敏感）。
3. 安全绳绷紧**并留够长度**（机身会升到离地 20 cm 以上）；人站在侧面，手随时能托住机身。
4. 白板笔：每只脚放好后，沿吸盘边在玻璃上画一道短线（地面脚画后边，墙面脚画下边），滑没滑就看它。
5. 手机固定在机器人**左侧**，和机身同高、正对着。每步做完拍一张：照片里 L1、L3 两个 femur 舵盘中心的
   连线与地面的夹角，就是真实俯仰。
6. 钢尺：每段 `↑` 做完，量一下**后腿 femur 最低处离地**多少。
7. 站位：前腿 coxa 舵机轴离墙 **135~142 mm**（干跑都能到 56°；140 时每次拒绝都和下表一字不差）。

## 2. 命令

```bash
python scripts/mount_wall.py --dry --support-legs L1,R1,L2,R2,L3,R3 \
    --wall-dist 140 --pitch-step 2 --pitch-max 70
```

| 参数 | 为什么 |
|---|---|
| `--dry` | 泵不转，吸附状态机是仿真的；**真阀照常动**：站着时断电（被动吸住无妨），抬腿前通电放气 0.3 s，落下压好后断电。屏幕上的盘压、罐压、泵开/停、"吸附完成"都是假的，不用看 |
| `--support-legs` 六条全写 | 引擎把六条腿都当"压到位就算站住"：不抽气，倾角容差 35°。⚠ 这些腿不参与互锁：**没有"其余脚站稳了才许抬腿"这道保护，引擎也不算会不会翻**，全靠人看 |
| `--wall-dist 140` | 就位暂停时量一下，按 `d` 填实测值 |
| 不给 `--wall-height` | `w` 取当前俯仰下可落足带的中点，每次换前足，落点自己往上走 |
| `--pitch-step 2`、`--pitch-max 70` | 每次 2°，最高 70° |
| 不给 `--fwd-reach`、`--handover`、`--takeover` | 干跑是按不给算的 |

## 3. 步骤

全程规则：

- **只按表里的键。** `↑` 被拒什么都不会动，多按无妨；表外的 `]` `←` `→` 不要按（会改变后面的路线）。
- **`↑` 段**：按到表里写的角度。中途被 `femur 离地` 或 `机身/腹面撞地面` 拒，就按一次 `]` 再按 `↑`；
  括号里是干跑按 `]` 的次数。**到了表里的角度就停，不再按 `]`。**
- 抬腿时先原地停 0.3 s（开阀放气）再抬，这是正常的。
- 每次按 `i` 后，看吸盘唇边确实压在玻璃上，再画线。**墙面脚没压上**：选中那条腿按 `.`（往墙里多压 2 mm），
  一次加一点。
- 每步做完停几秒，看一圈笔线再往下。指令 16° 以上的姿势实机没摆过，腿、膝、机身互相碰到也要停。

## 4. 什么时候停（出现任何一条）

- 任何一只脚离开笔线超过 3 mm，或者还在慢慢挪：机身正在动就按 `空格`（停在半路），手托住，
  记下"第几步、哪只脚、往哪滑、滑了几毫米"。
- 抬一条腿时机身往那边歪：托住；那条腿还悬停着就按 `i` 放回去。
- 抬腿时吸盘粘着不离开玻璃（阀没开？）：托住，`o`×2 冻结，查那一路阀。
- **后腿 femur 最低处离地不到 1 cm**：停，记下第几步、离地多少（说明 femur 净空标定偏小，要重新规划）。
- 电流持续超过 4 A 不回落（吸附路线实测最高 3.5 A）：腿在硬顶，记下来，按 `↓` 退一档。
- 冻结，或屏幕出现 ⚠ 开头的行：原样抄下来。

## 6. 判据（跑之前定死）

| 结果 | 说明 | 下一步 |
|---|---|---|
| 照片量出 ≥ 60°，静置 30 s 不滑 | 前期不抽气这条路成立 | 设计 70° 以后的抽气段。负压要 −40~−60，而现在泵的开停阈值写死在 −60 / −75（`adhesion.py`），要改 |
| 到第 21 步不滑，但照片不到 60° | 摩擦够，差在机身下沉和指令实现率 | 做第 22 步；或者从这里直接接抽气段 |
| 第 14~21 步滑了 | 摩擦加被动负压不够（光算摩擦要 0.31~0.38） | **后足往后滑** → 地面后足改成抽气吸住；**前足沿墙往下滑** → 先试前腿按 `.` 多压 2~4 mm，还滑就把墙面脚抽气提前，不必等到 70° |
| 第 8 步抬中腿时歪或滑 | 5 个脚时侧向靠前足的墙面摩擦兜着（要 0.51） | 记下来，重排中腿换位的时机 |
| 后腿 femur 比预测更早贴地 | femur 净空标定偏小 | 把各步实测离地发给我，改 `FEMUR_FLOOR_CLEAR_MM` / `FEMUR_SAG_MM_PER_DEG` 后重新规划 |
| 第 7 步以前就滑了 | 不是重量的问题（这几步算出来不需要摩擦），是前腿顶墙把机器人往后推 | 前腿按 `,` 少压 2 mm 再试 |

## 7. 干跑是怎么算的

- 真引擎（`MountEngine`）按第 3 节逐键重放，六条腿只承重，表里的角度、高度、拒绝都是干跑结果。引擎不读
  传感器，站位和按键一样，实机的拒绝点就一样（E5b 实测过，与干跑一字不差）。按"到表里的角度就停"的按法，
  站位 135/138/142 mm 都能到 56°（第 22 步那几下只在 140 时一字不差，其他站位能到 58°）。
- 路线是在"只靠摩擦系数 0.6 以内静力可行、中腿撑到 34° 才收"的约束下搜出来的。
- 静力：每次抬腿、每档俯仰都求一次"有没有一组接触力能让机身不动"（脚只能推，摩擦力不超过摩擦系数×压力），
  二分出最小摩擦系数；扭矩按"让最大关节扭矩最小"的受力分配求。重心按整机 3.54 kg、每条腿 0.32 kg 分到
  髋 / F / 膝 / 小腿 / 足来估。**只算了摩擦，没算被动负压**，所以偏保守。
