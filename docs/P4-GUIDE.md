## 第 0 步 · 先想清楚的三件事（影响后面所有工序）

**1. 步态引擎要做结构性改造，不是调参。** P3 的 `gait.py` 是纯开环相位表：
假定地面永远在 z0、触地精确发生在相位边界；触地瞬间垂直速度恰好最大
（默认参数 ≈170mm/s，"拍地"）；一过相位边界立刻横向拖脚。这三条对
"落脚即密封"全是反的。P4 要把它改成**事件驱动**：相位推进能被每条腿的
吸附事件暂停，摆动相收尾变成"减速竖直下探 → 压入 → 等真空确认"。
详见第 4 步。

**2. 吸附账要按实测重量重算。** P4-BAY-DESIGN §2.4 已泼过冷水：吸附系统
隐含预算 0.6kg，粗估 0.94~1.11kg，整机真实落点估计 2.6~2.8kg。单吸盘竖直
玻璃实测：法向拉脱 25N、剪切 15N（CLIMBING-DESIGN §漏项）。五足支撑剪切
承力 75N，对 2.8kg（28N）安全系数 ≈2.7——还活着，但每件到货必须称重记
`weight-log.md`，上墙前用实测整机重量把这笔账重新算一遍写进本文件验收表。

**3. 舵机保护三原则**（P3 舵机讨论的结论，贯穿全部步态设计）：

| 原则 | 落实 |
|---|---|
| 瞬态外力可接受 | 偶发的吸附拽动、没压够重试，不用追求零外力 |
| **稳态对抗必须靠改指令消除** | PWM 舵机没有单路使能/力矩模式/位置回读，唯一手段是让指令跟着物理走（预压行程,第 4.2 节）；判据 = 吸附后总电流回落基线 |
| 绝不超堵转 | 35kg·cm 按 50% 降额（P2 实测口径）；步态宁慢勿快；使能中永远不许手掰 |

墙上与地面的本质区别：支撑足在墙上**持续**承剪切载荷（P2 实测单腿 hold
0.61A），五足支撑就是 ~3A 级持续电流 + 持续发热。这是常态不是异常——
`walk_teleop` 式的电压/电流状态行必须保留并加峰值/单足回落判据。

## 第 2 步 · 电气与 IO：`Pi5VacuumIO` 从 1 足扩到 6 足（2~3 天）

现在的 `adhesion.py` 是 P1 台架版：`VALVE_PINS = [5]`、单泵、单 ADS1115。P4 扩展：

1. **通道分配**：YYNMOS-8 恰好 8 路 = 6 阀 + 2 泵（首飞泵 2 路并定义、只接 1）。
   GPIO 引脚表定下来写进 `Pi5VacuumIO` 类常量，和 `config.py` 的腿序一一对应。
2. **压力 7 路**：2 块 ADS1115（0x48/0x49）共 8 通道，足压 ×6 + 罐压 ×1。
   足压传感器装**阀与吸盘之间（吸盘侧）**——阀关着也能读脚压，吸附确认和
   打嗝检测都靠它（P1 单传感器教训 + P2 打嗝实测 30s 进失控）。
   PGA 必须 ±4.096V（±2.048 在放气确认区间削顶,见 `adhesion.py` 注释）。
3. **逐路电学验证**（不接气路）：每路阀听得到吸合声、每路传感器大气点读数
   一致（V_ATM 逐只标定,7 只写成表）、泵能起停。
4. **仲裁位**（远期双墙面混合足预留）：`AdhesionController` 的步态层接口里
   给每足留一个 `mode` 字段占位，本阶段恒为 `suction`，不实现任何逻辑。
5. 舵机总电仍走 A0 高边继电器（切正极）；断舵机电不影响 Pi 和气路——这是
   墙上急停的分级基础：先断舵机（常闭阀保真空，机器人挂住不掉），人再接。

## 第 4 步 · 软件线：步态引擎改造（本阶段核心工作量，2~3 周，Mock 上先行）

### 4.1 摆动相从"一条曲线"改成分段状态机

每条腿的摆动相拆为（配合 `adhesion.py` 每足状态机）：

```
LIFT     通大气的同时抬离：足端目标沿面法向退开 ≥15mm（吸盘回弹行程 11~13mm
         会把脚顶回面上，必须边放气边走）
TRANSFER 平移到落点上方：沿用现有 smoothstep + 正弦抬腿形状
DESCEND  落点正上方竖直减速下探：XY 冻结，接近速度压到慢速（几十 mm/s 级，
         架空实测定值）——消灭现在"触地瞬间垂直速度最大"的拍地
PRESS    压入预压行程 press_delta（见 4.2）：XY 继续冻结，慢速；
         结束即 adhesion.request_attach(i) → PRESSING → SUCKING
WAIT     等 ATTACHED（-30kPa）；相位推进在此暂停，抽不上转 FAULT：
         抬 5mm 回 DESCEND 重试，连续 3 次失败 → 全机停走报警
LOAD     ATTACHED 后：足端目标切到压入后的位置保持（4.2），该腿转支撑相
```

支撑相和释放对称：重心先移走（该腿卸载）→ `request_release` → VENTING →
RELEASED → 才允许 LIFT。

### 4.2 预压行程与两态足端目标（消灭稳态对抗的关键）

§4.4 三态实测（LEG-GEOMETRY-OPEN.md）换算成步态参数：

| 状态 | h_cup | 含义 |
|---|---|---|
| 自由 | 19~21mm **按腿各测** | 摆动相几何，定案 l3=123.7 基于 L1 的 19 |
| 压到密封 | 7.5mm | **press_delta = h_cup_free − 7.5 ≈ 11.5~13.5mm** |
| 真空 -40~-50kPa | 8mm | 与密封态只差 0.5mm——**先压密封再抽气，抽气几乎不再动** |

实现口径：**不改动定案 `tibia_len=123.7`**，在 `config.py` 每腿新增
`press_delta_mm`，步态在触地点沿面法向加这个量作为压入段与吸附保持段的
足端目标。两态 l3 与"目标点加 delta"数学等价，后者不碰已定案的标定链。
（关联件：`workspace_analysis.py` 的 `CUP_DELTA=-25.2` 已按吸附态修订
——L3-DISPUTE 待办 g——落点带用它复核。）

**验收判据（每次实机跑都看）**：ATTACHED 并切换目标后 ~2s 内，总电流应
回落到接近该支撑构型的基线。某腿吸附后总电流持续多挂 ~0.6A = 该腿
press_delta 没吃干净（复测该腿 h_cup），舵机在和真空对抗。

### 4.3 落点与唇口姿态约束

- 唇口倾角容差 **±15°**（P1 台架实测）。3DOF 腿控制不了吸盘朝向——倾角由
  落点位置几何决定，所以这是**落点选择约束**（workspace 层），不是步态能
  逐步补的。平地/竖墙在设计站姿附近天然满足；落点带越界的步长直接拒绝。
- 压入方向沿面法向、XY 冻结是**步态硬规则**（4.1 已定），否则唇口蹭移密封失败。

### 4.4 触地判据

平面位置已知（地面/玻璃墙都是平的），主路线用**开环压入 + 电流监护**：
DESCEND 段按已知平面高度走到位再转 PRESS，全程盯总电流增量做两件事——
撞早预警（还没到预期高度电流就陡增 → 停）和触地确认。总电流分辨率
81mA/LSB，单腿压入增量百 mA 级可辨，阈值靠架空 vs 落地对比标定。
足压传感器是第二判据：PRESS 结束开阀后压力不降 = 唇口根本没贴上。

### 4.5 CLIMB 步态与安全互锁

- 用 `gait.py:29` 预留的 CLIMB（5/6 占空，wave 相位，一次一腿）。三角步态
  两腿组同时吸放，泵和时序都紧张，爬墙不用。
- 互锁（比 `adhesion.py` 注释的 ≥4 更严，首爬用严的）：**抬任一足前，其余
  5 足全部 ATTACHED**；相邻足不同时释放（CLIMBING-DESIGN §漏项约束）。
- ATTACHED 漏气报警（压力回升 >10kPa）：该足立即重抽挽救；挽救 2s 无效 →
  全机冻结当前姿态 + 报警（五足里坏一足还有 4 足,安全系数仍 >2）。
- 泵滞环沿用 -55/-65kPa；步态周期先放到 3~4s（cycle_time 可调），跑顺再提速。

## 常见问题

| 症状 | 处理 |
|---|---|
| 某腿 SUCKING 频繁超时 | 按序查:唇口倾角(落点在工作带边缘?)→ press_delta(该腿 h_cup 实测过没?)→ 该路气管/三通泄漏 → 唇口酒精清洁 |
| 吸附后总电流不回落 | press_delta 没吃干净,舵机对抗真空;复测该腿两态 h_cup(杯批次差 2mm,别用 L1 的值套全部) |
| 打嗝(足压周期性回升又抽回) | P2 老对手:微泄漏。唇口清洁、检查该足吸盘座密封;打嗝超 30s 按失控处理(P2 实测教训) |
| 罐压跟不上步频 | 先放慢 cycle_time,再上第二泵;泵一直响不停 = 系统性泄漏,回第 3 步验漏 |
| LIFT 时脚被"粘"在面上拖 | 放气没到位就抬(VENT_TIME/RELEASE_KPA 判据没等到)或该路阀排气堵 |
| 抬脚瞬间整机晃动 | 释放前重心没移够,该腿还承着载;检查支撑多边形计算 |
| 走几步某舵机烫 | 墙上持续载荷是常态,但单腿明显更烫 = 承载不均或残余对抗;对照电流曲线找腿 |
| 墙上 Pi 重启 | 欠压=坠机级事故。立即停,查 5V 独立供电与 `get_throttled`,修好前不上墙 |
| 阀通电反而吸不住 | 常闭阀口接反(进/出/排气三口)或 `VALVE_ON_LEVEL` 电平反 |
| 断电悬停掉压快 | 逐段验漏定位;接头补环氧;唇口清洁;罐容量复核 |

## 安全

- **安全绳全程不摘**,包括斜面级;打点先做人力冲坠测试;绳留轻微余量不影响步态。
- 垫子铺满作业面正下方;首爬高度 0.3m。
- 断电悬停测试人站机器旁,手虚扶不接触。
- 舵机使能中不许手掰任何关节(35kg·cm 打齿);调整姿势先断舵机电——
  常闭阀会保持吸附,机器人不会掉。
- 墙上任何异常(打嗝、FAULT 级联、异响、烫)先冻结姿态观察,不要急着继续走;
  吸附态冻结是安全态,乱动才危险。
- 锂电规矩同 P0~P3:充电不离人、XT60 随手可拔、先断电再改线。
