# 地-墙过渡 · 摩擦上墙前期（地面脚只压不吸、墙面脚抽气吸住）

> 目的：地面脚只压不吸（靠摩擦），前脚上墙后抽到 −60 kPa 吸住、之后不补抽，看能抬多高、滑不滑。
> 为什么前脚要吸（09-14）：六脚都不吸时抬 L2，机身往左塌、把 L1 的吸盘拽下来。
> 规则只有一条（09-13 定）：**在地上的脚，吸盘轴尽量垂直地面；斜了就抬起重放到最正的点，需要转 coxa 就转；步子小、多迈几步。**
> 脚压在地上是滑不动的，所以"贴地随动"作废，所有挪脚都是抬起 → 摆过去 → 落下。
> 阀和泵都是程序管的，不用操心：站着六路线圈全断（不发热）；抬腿前通电放气 0.3 s；前脚踩上墙压到位后，先把其余五路通电隔离（约 0.5 s），泵抽到 −60 就停、其余断回；墙面脚吸住后不再监护、不补抽（靠单向阀锁住）。
> 屏幕会告诉你哪只脚该重放（`v`）、哪只中腿该收起（`h`），照着按就行。
> 干跑（模型）走到指令 58°；实机比模型斜，走到哪算哪，量出真实角度和机身下沉，回来修引擎。
> 当前问题与方案在 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md)；历次版本的原因分析、干跑数据、实机记录在 [WALL-MOUNT-HISTORY.md](WALL-MOUNT-HISTORY.md) §4.7。跑之前先 `git pull`。

## 1. 准备

1. 气管、泵照常接着；地面、墙面玻璃擦干净、擦干。
2. 安全绳绷紧、留够长度（机身会升到离地 20 cm 以上）；人站侧面，手随时能托住机身。
3. 站位：前腿 coxa 舵机轴离墙 135~142 mm，就位暂停时按 `d` 填量到的数。
4. 白板笔：每只脚放好后沿吸盘边画一道短线（地面脚画后边，墙面脚画下边），滑没滑看它。
5. 手机固定在机器人左侧，和机身同高、正对着；钢尺。

## 2. 命令

```bash
python scripts/mount_wall.py --no-tank --wall-suck --auto-adjust --wall-dist 140 \
    --pitch-step 2 --pitch-max 70 --floor-clear 100 --handover L1:10,R1:10
```

`--wall-suck`（09-14 加）：踩地面的脚只压不吸，踩墙的脚抽到 −60（`--attach-kpa`）即算吸住；一次最多抽 6 s（`--suck-timeout`），抽不到就回抬加深重试，3 次都不行全机冻结（查吸盘对没对正、软管折没折）。泵和阀都是真的，**不再配 `--dry`**。有储气罐的机器也照样 `--no-tank`：这个模式下泵只在抽气时开，罐会拖慢抽气。

`--handover L1:10,R1:10` 是零力交接：前腿抬起前先把它的力卸到零、其余五条腿各多压 2 mm，抬腿那一下机身不再往前塌。
状态行里该腿先 `Z` 再 `V`、`L`；落定后 `z` 还账。**只给前腿**：后腿、中腿落地会把欠账压到自己身上（18+δ），离压深上限 28 太近，给了会把收中腿卡死。
不再带 `--slide-legs`。`--tilt-warn 10`（地面脚超过就提示重放）、`--tuck-tilt 25`（中腿最正也超过就提示收起）是默认值，实机觉得 10° 还太斜就改小。
墙面脚的门槛是 `--wall-tilt 25`：引擎按它放行（超过 25° 的 `↑` 会被拒），提示会在"再抬一档到 22° 以上"时就叫你重放，留 3° 给交接。

**站着时中腿吸盘就不垂直（往外斜）**：加 `--tilt-trim L2:6,R2:6`。这是告诉程序"这两条腿的吸盘轴实际比模型算的向外斜 6°"，
程序会把它们的站位往身体收（每 1° 约 2 mm，6° 收 12 mm），之后 `v` 的最正点、提示也都按这个算。先试 6，站起来看中腿吸盘还斜就加到 8、10；
别的腿也斜就一起写，比如 `L2:8,R2:8,L3:3,R3:3`。
状态行：`盘差 L1 -62.0` 是最软的那只墙面盘的压力；`阀电 L2L3R2R3` 是此刻线圈通电的腿，只在抬腿和隔离时出现，站着不动时这一项应该是空的。

## 3. 步骤

**上一个动作做完再按下一个键**：机身动完打"位姿铺完"，腿放好打"收口"。这两行之后屏幕紧接着打一行
`⚠ 该重放：…` 或 `各脚离面法线都在门槛内`，照它按。状态行末尾 `轴 L1:3 L2:12! …` 是每只脚吸盘轴离面法线的角度，带 `!` 的就是该重放的。

| # | 按键 | 看什么 |
|---|---|---|
| 1 | 就位暂停：量距 → `d` 填 → `p` | 六个脚压到位；泵不响、线圈全断 |
| 2 | `1 w i`，`4 w i` | 两前足上墙：落下 → 其余阀通电隔离 → 泵响 1~3 s → 屏幕打 `L1 收口：墙面 已吸附 -6x kPa`。抽不到会自动回抬加深重试 |
| 3 | `3 b i`，`6 b i` | 后足指向正后（和身体平行），吸盘轴垂直地面 |
| 4 | `↑` | 抬 2°，等"位姿铺完"和提示 |
| 5 | 提示有 `n v` 就按 `n v`（n = 腿号）。地面脚会自己落下；前脚会悬停，目测离玻璃约 15 mm（`.` `,` 调）再按 `i` | "收口"和新角度；前脚每次重放都重新抽一次 |
| 6 | 提示写着"先 ↓ 一档再 `n v`"就先按 `↓` 再按 `n v` | 两只前脚都贴着 25° 时，重放谁都会被对面那只顶过线 |
| 7 | 提示有 `n h` 就按 `n h`（收起中腿，从此只剩 4 个脚，盯紧笔线） | |
| 8 | 回到第 4 行，直到 `↑` 打出 `位姿拒绝（抬头 2°，自动补高度/前后也不行）` 而且提示里没有可按的键 | |
| 9 | 静置 30 s；记电流，钢尺量后腿 femur 最低处离地、L1 和 L3 的 F 点离地、前足吸盘离地，拍侧面照 | |
| 10 | **先托住机身** → `o`×2 → 抱下来 → `ESC`×2 | `o`×2 会放掉墙面吸盘；`ESC`×2 会给舵机断电 |

`v` 被拒（"落点不可行 / 路径不可行"）不用管，继续 `↑`，下一档再按。一次提示里有几只脚就按几只，先中腿后后腿再前脚。
每条腿能按哪些键、按了发生什么，按腿写在 [WALL-MOUNT-OPEN.md](WALL-MOUNT-OPEN.md) §5。

**眼睛和屏幕不一致时**：
- 地面脚：屏幕说正、眼睛看着斜（09-13 实机：后腿）——选那条腿按 `>`，意思是"它实际比算的向外斜 2°"，状态行里它的角度会涨；看着斜得多就多按几次，然后按 `v` 重放（每 2° 往身体收约 4 mm）。屏幕会打一行 `下次启动用 --tilt-trim L3:6,R3:6`，下次带上就不用再按。
- 墙面脚：屏幕说该重放、眼睛看着正（前脚吸盘的波纹贴平玻璃后杆斜十几度看不出）——**照屏幕按**。墙面脚现在是吸住的，引擎按 25° 卡，不重放下一档 `↑` 就被拒。

干跑参考（站位 140，模型，09-14 按上面的命令自动走的；实机会不一样）：

| 抬到 | 提示会让你按 |
|---|---|
| 10° | `1 v i`、`4 v i`（前脚上挪到离地 245，吸到 −66/−68） |
| 12° | `2 v`、`5 v`（中腿转 coxa 重放，12°→7°） |
| 20° | `1 v i`、`4 v i`（276）；这一档 `2 v`、`5 v` 会被拒，不用管 |
| 22° | `5 v`（`2 v` 被拒不用管） |
| 24° | `2 v`、`3 v`、`6 v` |

## 4. 什么时候停

出现下面任何一条：手托住机身（机身正在动就先按 `空格`，停在半路），记下几度、哪只脚。

- 任何吸盘离开笔线 3 mm 以上，或者还在慢慢挪。
- 抬腿时机身往那边歪、吸盘粘着玻璃不走，或腿抬空了还蹭地。
- 状态行 `盘差` 里墙面脚的压力升到 −40 以上（程序不补抽；先按那只脚的 `v i` 重放吸一次）。
- 某只脚看着比屏幕上的角度斜得多（机身压弯了腿）。
- 后腿 femur 离地不到 1 cm，或腿、膝、机身互相碰到。
- 电流持续超过 5 A，或舵机摸着烫手；阀线圈烫手（站着不动时 `阀电` 应该是空的，不空就是程序有问题）。
- 屏幕打 `⚠⚠⚠ 全机冻结`。

## 5. 记录

每次 `v` / `h` 之后填一行，没事的格子空着：

| 抬到 | 按了什么 | 电流 A | 屏幕角度（前/后） | 墙面盘压 | 目测斜不斜 | 滑了吗（哪只脚、往哪、几 mm） |
|---|---|---|---|---|---|---|
| | | | | | | |

终点另记：后腿 femur 离地、L1 / L3 的 F 点离地、前足吸盘离地、侧面照。
交接有没有用看两处：`1 w i` 做完、`4 w i` 做完各量一次 L1、L3 的 F 离地（或看笔线），和没开交接那次比（吸附路线的口径是 9 → 5、15 → 5 mm）。
日志（`software/logs/mount_*.log`，提示、拒绝原话、⚠ 行、每次阀线圈通断都在里面）和照片传到开发机（在 Pi 上跑 `software/scripts/pi_sync_logs.sh`）。

## 6. 判据

- **走到 `↑` 被拒、静置 30 s 不滑**：这段成立。按量的数修引擎（机身真实沉了多少、femur 余量对不对），再接后腿上墙那段。
- **前脚抽不到 −60（回抬重试 3 次冻结）**：看冻结前屏幕的盘压走到哪，量吸盘对墙的角度；把日志发我。
- **某次 `v` 之后那只脚滑**：重放的落点不对，把那一行记录发我。
- **中腿收起后滑**：后足往后滑 → 把记录发我，商量地面后足也抽气；前足沿墙下滑（已吸到 −60）→ 剪切超了单盘容量（15 N），把那一行记录发我。
- **屏幕说 ≤ 10° 但眼睛看着明显斜**：机身压弯了腿，实机比模型斜；`--tilt-warn` 改小（8、6）再跑，并把量的数发我。
