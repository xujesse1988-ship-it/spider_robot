零力交接 δ 三组标定：弹跳 ≠ 储能

2026-08-24 · 玻璃墙原地逐腿抬落（窗序 R3→L1→R2→L3→R1→L2，各约两轮半）· 代码 dd778e6 · iPhone 16 Pro Max 4K@30 HEVC 原片 · NCC 追踪机身 PCB + 危险条纹胶带静物参照修正（手持级抖动 22~25px 已扣除）· 比例：cm 刻度纸 0.358 → 玻璃平面 0.318 mm/px（本页毫米口径，绝对值 ±10% 系统不确定度；δ* 外推与比例无关）· 结论已落地：2990449（δ 解析上限 25→45 + 标定法改线性外推）

TL;DR：δ=0 / 12 / 24 三组对照显示，逐腿 vent 弹跳对 δ 严格线性下降但 δ=24 顶格仍全体下弹——外推零弹跳需要 δ* ≈ 28~42mm/腿（前腿 ~40）， 全部超过当时 25mm 的解析上限。根子是标定语义错误：放气瞬间的弹跳只是储能被其余五腿 并联接住后的读数（≈储能的 1/5~1/8），δ 要还的是储能本身——"弹跳×0.8"起标表因此系统性 低了 4~8 倍。每轮总下滑 66 → 50 → 39mm，方向对、剂量不足。 交接机构本身工作正常（交接段身体位移基本为零，判据 4 通过）。

2. 数据质量与两则勘误

勘误一：ab_quant 活动对比度对时三组全错。 A 组错 1 个抬落间隔（off 83.25 vs 真值 76.14，对比度 0.1 明显失锁），B/C 组错 5~6 格 （82.05/93.70 vs 47.24/53.14）——且 B/C 的对比度 4.8/8.6 看着健康：抬落节奏准周期， 错位整数格照样得分。根因 = 协议 §4.3 的 ↑↓ 倾身对时标记被跳过 + 录像里没有首抬前的安静参考段。 本页全部数字基于阶跃基底回归重排（y(t) 用 18 个 rel 时刻的阶跃最小二乘拟合， 三组 R² = 0.9998 / 0.9997 / 0.9995，与次优峰差距显著；脚本 ~/ab_cache/redecompose.py）。 下次实验务必做对时标记；管线加阶跃回退/--off 手动口另议。
勘误二：比例标定无胶带尺，走三平面几何。 背景是 1m 高 cm 刻度纸（上下格距均匀 27.9px/cm → 纸面 0.358mm/px），但纸面在玻璃后约 9cm， 与吸盘平面有视差。用镜头 FOV + 接头高度差闭环推得玻璃平面 ≈0.318、机身平面 ≈0.27mm/px。 本页毫米数取玻璃平面口径（与 08-20 胶带尺贴玻璃的惯例可比），绝对值 ±10% 系统不确定度； δ* = 截距/|斜率| 分子分母同比例，外推结果与标定无关——这是本实验最硬的数字。

追踪健康：body_score 中位 0.85 / 0.93 / 0.88，ref_score min ≥ 0.67；相机抖动（ref_y 范围） 22~25px 属手持级，已按静物参照逐帧扣除——扣除后轨迹能被纯阶跃基底解释到 R²≥0.9995， 本身就是追踪干净的证明。

4. 每轮下滑与轨迹

剂量-响应干净：第 2 轮总下滑 65.6 → 50.0 → 38.7mm（−24% / −41%）。 方向对，但离协议 <10mm/轮 的达标线还远——δ=24 只还了各腿储能的 58~86%。

三组轮内形态一致（轮 1 含首轮爬坡、轮 3 各缺 L2 末次），说明下降是 δ 的作用而非日间漂移； A 组形态与 08-20 基线咬合（L1/R1 最大、总量 66 vs 74，−11% 在日差范围内）。

图 3 · 三组身体轨迹（累计下滑 mm，向下为正；参照修正后）。顶部刻度 = 各次密封破裂时刻（rel）。 三组都是干净的阶梯：位移几乎全部发生在破裂瞬间，δ 只是把每级台阶变矮——慢泄压无效的 08-20 结论继续成立。

5. 机理验证三项

  1. 线性 ⇒ 储能不随 δ 变。交接给支撑腿的份额在轮转中被精确归还（几何闭环）， 所以加大 δ 不降低系统的绕紧水平，只在放气瞬间多抵扣一份——三点共线正是这个预言。
  2. 阶跃基底 R²≥0.9995 ⇒ 位移仍集中在破裂瞬间。包括 δ=24 组：交接改变的是台阶高度， 不是位移发生的时刻。
  3. 交接段身体位移 ≈ 0（判据 4 通过，带一个已解释的例外）。B 组全部 ≤0.7mm； C 组除 L1 达 +2.4~+3.3mm（贴协议 3mm 线）外全 ≤2mm。L1 的微沉是刚度不均的固有物理： 卸载全机最硬的腿时，k 加权的力学均衡点必然向软侧移一点，量随 δ 线性长——不是分摊方向 bug， 判读时按"上坡侧小台阶"同类放行。

6. 电流：棘轮仍在，且"总电流找平台"的 v2 原始设想被数据否了

整机电流（驱动板 ADC，量化 81mA/LSB）：三组静置起点均 ~0.76A，结束静置 1.65 / 2.39 / 2.90A 不回落——δ 没到位则内应力照旧累积（跨组绝对值受电池状态干扰，仅作定性）。

R1#1（卸前腿：降到"平台"） R2#3（卸中腿：总和反升）

图 4 · C 组两次交接窗内的总线电流（泵停样本，0.5s 采样；t=0 交接开始，虚线 = 铺满 δ=24 放气）。 R1 在 δ≈10mm 铺完时就"降到平台"——但视频量化显示 R1 在 δ=24 仍残余 6.9mm 弹跳（δ*=41）： 总和电流的拐点是"卸载增益 = 接载增益"的平衡点，不是零力点。R2 更直接：自身储能小、 接载份额压向本来最重的前腿，总和一路上升，无下降信号可用。

对 v2 的含义：整机总电流当逐腿零力检测器不合格，当残余量遥测够用—— 改在密封破裂瞬间量电流台阶（破裂时刻由盘压 venting→released 转移给出；排气阀线圈 在破裂前 0.4s 已通电、差分自动抵消；50Hz 逐 tick 采样即可），台阶高度 ∝ 残余储能， 直接喂协议 §6 的逐腿修正规则——从此标 δ 不需要架相机。终局传感器是 IMU （破裂瞬间的机身加速度脉冲比总线电流干净一个量级，顺带收编 _down 真实重力方向）。
